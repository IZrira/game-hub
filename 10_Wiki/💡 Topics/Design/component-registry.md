# Rira Game Hub 컴포넌트 레지스트리

공통 컴포넌트의 현재 위치와 역할은 `docs/design-system/components.md`에서 관리한다. 시각·UX 정책은 루트 `DESIGN.md`가 우선한다.

Wiki에는 Props나 스타일 규칙을 복제하지 않는다. 실제 구현 전에는 문서와 해당 컴포넌트의 TypeScript 인터페이스를 확인한다.
