# Rira Game Hub 디자인 시스템

Rira Game Hub의 디자인·UX 정책은 프로젝트 루트의 `DESIGN.md`가 유일한 기준이다.

- 정책: `DESIGN.md`
- 컴포넌트 레지스트리: `docs/design-system/components.md`
- UX 상태 체크리스트: `docs/design-system/ux-principles.md`

이 Wiki 문서에는 정책을 복제하지 않는다. 정책 변경 시 루트 문서를 먼저 수정한다.
