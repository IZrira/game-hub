## 🗂️ 1. 노션 데이터베이스 프로퍼티 규격 (Database Schema)

- **Notion Database ID:** `38095fae3dc780c3a7c4d901cbe9411c`
- **Notion URL:** [NTE 아크 DB](https://app.notion.com/p/riragame/38095fae3dc780c3a7c4d901cbe9411c?v=38095fae3dc780948bea000cf3524c88&source=copy_link)

| 프로퍼티명 | 노션 속성 타입 | 데이터 형식 / 예시 | 처리 및 렌더링 규칙 |
| :--- | :--- | :--- | :--- |
| **아크명** | 텍스트 / 제목 (Title) | `물망산` | 아크 고유 명칭 및 URL 슬러그 매핑 |
| **등급** | 선택 (Select) | `S`, `A`, `B` | `S` (5성 / 골드), `A` (4성 / 퍼플), `B` (3성 / 블루) |
| **종류** | 선택 (Select) | `결합`, `고체`, `액체`, `기체`, `플라즈마` | 아크 형태 계열 분류 및 도감 필터 옵션 |
| **성장 스텟** | 텍스트 (Rich Text) | `1 : 공격력 25/ 방어력 21%`<br>`20 : 공격력 106 / 방어력 26.25%`<br>...<br>`80 : 공격력 395 / 방어력 52.5%` | 1~80Lv 슬라이더 연동 및 레벨별 기초 공격력 & 부옵션 동적 표시 |
| **스킬명** | 텍스트 (Rich Text) | `「레인맨」` | 아크 고유 발동 스킬 명칭 |
| **스킬 설명** | 텍스트 (Rich Text) | `HP+10%/12%/14%/16%/18% ...` | R1~R5 중첩 슬라이더와 연동하여 수치 하이라이트 |
| **돌파 재료** | 텍스트 (Rich Text) | `비틀 코인x336,000`<br>`흐릿한 숫자 부호x11`<br>`철 사과씨x11` ... | 줄 단위 파싱 후 `ItemIcon` 이미지 출력 및 인벤토리 상세 모달 연계 |
| **아크 스토리** | 텍스트 (Rich Text) | `잘 자고, 일기예보 확인하는 거 잊지 마...` | 아크 고유 배경 스토리 본문 렌더링 |
| **전용** | 텍스트 (Rich Text) | `라크리모사` (또는 빈 값) | 값이 있는 경우 `[캐릭터명] 전용` 뱃지 렌더링, 없는 경우 생략 |

## ⚡ 2. 등록된 아크 레퍼런스 데이터 (`물망산`)

- **등급:** `A` (4성)
- **종류:** `결합`
- **성장 스탯 테이블:**
  - **Lv 1:** 기초 공격력 25 / 방어력 21%
  - **Lv 20:** 기초 공격력 106 / 방어력 26.25%
  - **Lv 30:** 기초 공격력 157 / 방어력 31.5%
  - **Lv 40:** 기초 공격력 208 / 방어력 36.75%
  - **Lv 50:** 기초 공격력 259 / 방어력 42%
  - **Lv 60:** 기초 공격력 310 / 방어력 47.25%
  - **Lv 70:** 기초 공격력 362 / 방어력 52.5%
  - **Lv 80:** 기초 공격력 395 / 방어력 52.5%
- **스킬:** 「레인맨」
  - *HP +10%/12%/14%/16%/18%*
  - *착용자의 HP가 50%보다 높은 경우, 자신의 방어막이 10%/12%/14%/16%/18% 강화된다.*
- **돌파 재료 (Breakthrough Items):**
  - [[비틀 코인]] x 336,000
  - [[흐릿한 숫자 부호]] x 11
  - [[미해독 숫자 부호]] x 15
  - [[뒤틀린 숫자 부호]] x 15
  - [[철 사과씨]] x 11
  - [[은 사과씨]] x 15
  - [[금 사과씨]] x 15
- **아크 스토리:**
  > *"잘 자고, 일기예보 확인하는 거 잊지 마. 밥 잘 챙겨 먹고, 우산도 잊지 마!"*
