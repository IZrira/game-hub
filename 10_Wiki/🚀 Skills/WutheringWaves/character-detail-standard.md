# [[character-detail-standard]]

## 📌 한 줄 통찰 (The Karpathy Summary)
> 명조 캐릭터 상세 페이지의 10단계 섹션 구조와 엄격한 에셋 매핑 규칙을 통해 데이터 가독성과 UI 일관성을 보장함.

## 📖 구조화된 지식 (Synthesized Content)
- **추출된 패턴:**
  - **섹션 고정 순서**: 프로필(01-03) -> 전투 역할(04) -> 육성 재료(05) -> 스킬 정보(06) -> 스킬 입력 가이드(07) -> 공명 체인(08) -> 관련 용어(09).
  - **에셋 명명 표준**: `공명 회로 게이지.webp` (단일), `공명 회로 게이지[N].webp` (다중) 및 `공명 체인[1-6].webp`.
- **세부 내용:**
  - **테마 컬러**: 속성별 고유 헥사 코드(예: 인멸-#F472B6) 정의.
  - **텍스트 하이라이트**: `[속성명] 피해` 자동 하이라이트 및 `==키워드==` 수동 하이라이트 적용.
