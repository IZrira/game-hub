# [[text-formatting-guide]]

## 📌 한 줄 통찰 (The Karpathy Summary)
> 마크다운 기반의 특수 기호(`==`, `**`)를 활용한 자동 스타일링 시스템을 통해 인게임과 동일한 시각적 피드백 제공.

## 📖 구조화된 지식 (Synthesized Content)
- **추출된 패턴:**
  - **자동 하이라이트**: `[속성명] 피해` 텍스트 감지 시 전용 속성 색상 자동 적용.
  - **수동 하이라이트**: `==키워드==` (노란색 글로우 + 툴팁), `**제목**` (골드 서브타이틀 블록) 처리.
- **세부 내용:**
  - **툴팁 규격**: 최대 너비 600px, `black/90` 배경, `backdrop-blur-xl` 효과 적용.
  - **아이콘 매핑**: `{{KEY_E}}`, `{{MOUSE_L}}` 등 중괄호 문법을 통한 조작 아이콘 인라인 삽입.
