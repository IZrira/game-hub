## 2. Logic Chain

1. **Problem Statement**: Search engines (Googlebot / AdSense crawlers) flag character detail pages as "Thin Content" when pre-rendered HTML only contains minimal raw skill titles without structured narrative synthesis or build recommendations.
2. **Solution**: During `npm run prerender` (or `node scripts/prerender-meta.js`), `prerender-meta.js` must load character metadata, guide recommendations (relics, light cones, target stats), and party synergy combinations, synthesize a multi-paragraph narrative analysis summary (`Character Analysis Summary`), and inject it into `<div id="root">` of static HTML files.
3. **Execution Strategy**:
   - **TS Guide & Party Data Loading**: Provide lightweight JS helper functions in `prerender-meta.js` to parse TS data files without requiring external TS runtime dependencies (`tsx` / `ts-node`).
   - **Narrative Synthesis**: Update `generateWwCharacterHtml(id)`, `generateHsrCharacterHtml(id)`, and `generateNotionHtml(item)` to format a `<section class="narrative-analysis-summary">` containing synthesized Korean prose covering:
     - Profile & Role
     - Best Equipment & Relics/Echoes
     - Target Stats & Main/Sub Stats
     - Recommended Team Synergies & Compositions
   - **Safe HTML Injection**: Replace exact string substitution with robust regex and function-based replacement to prevent HTML corruption or JS replacement token evaluation.

## 3. Recommended Code Strategy & Proposed Design

### A. Safe HTML Root Div Injection
Instead of exact string matching `injected.replace('<div id="root"></div>', ...)`, use regex with a replacer function:

```javascript
// Regex matching <div id="root">...</div> with optional attributes or whitespace
const ROOT_DIV_REGEX = /<div\s+id=["']root["'][^>]*>([\s\S]*?)<\/div>/i;

// Replacer function avoids JS replacement string tokens ($1, $&, $') in innerContent
if (innerContent) {
  injected = injected.replace(ROOT_DIV_REGEX, () => `<div id="root">${innerContent}</div>`);
}
```

### B. Lightweight TS Data File Loader Helper
Add helper functions to `scripts/prerender-meta.js` to parse `.ts` files:

```javascript
function loadTsDataFile(filePath) {
  try {
    if (!fs.existsSync(filePath)) return null;
    let content = fs.readFileSync(filePath, 'utf8');
    // Strip TypeScript import statements and type annotations
    content = content.replace(/import\s+[\s\S]*?;/g, '');
    content = content.replace(/interface\s+[\s\S]*?\n\}/g, '');
    content = content.replace(/:\s*[A-Z][a-zA-Z0-9_<>\[\]|]*\s*=/g, ' =');
    content = content.replace(/export\s+const\s+([a-zA-Z0-9_$]+)\s*=/g, 'const $1 =');
    
    // Evaluate stripped JS literal using Function constructor
    const exports = {};
    const evalFunc = new Function('exports', `${content}\nreturn typeof HSR_CHARACTER_GUIDES !== 'undefined' ? HSR_CHARACTER_GUIDES : (typeof WW_CHARACTER_GUIDES !== 'undefined' ? WW_CHARACTER_GUIDES : exports);`);
    return evalFunc(exports);
  } catch (error) {
    return null;
  }
}
```

## 4. Caveats & Edge Cases

1. **Missing Guide or Synergy Data**:
   - *Edge Case*: A character file exists under `characters/` but has no corresponding guide file in `guides/` or party combination in `parties/`.
   - *Handling*: Fallback gracefully to default narrative sentences (e.g., `"추천 유물 및 에코 세팅 정보 준비 중입니다."`) rather than outputting `undefined` or empty brackets `[]`.
2. **HTML Character Escaping**:
   - *Edge Case*: Guide notes or character names may contain `<`, `>`, `&`, `"`, `'`.
   - *Handling*: Implement an `escapeHtml(str)` helper function for all user-visible or guide-derived strings.
3. **JS Regex Replacement Token Collision**:
   - *Edge Case*: Passing `innerContent` directly as a string replacement argument `injected.replace(pattern, innerContent)` causes `$1`, `$&`, `$'` inside character text to trigger string substitution.
   - *Handling*: Always use function replacer: `.replace(pattern, () => replacement)`.
4. **Preservation of Existing Meta Tag Injections**:
   - Ensure title tags, OpenGraph (`og:title`, `og:description`, `og:image`), and Twitter card meta tag logic remain 100% intact while injecting content into `<div id="root">`.
