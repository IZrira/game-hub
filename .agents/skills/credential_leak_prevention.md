# Skill: Credential Leak Prevention

## Objective
환경 변수, API 키, 데이터베이스 패스워드 등 자격 증명(Credentials) 데이터가 코드베이스에 하드코딩되거나 Git 원격 저장소에 커밋되어 외부로 유출되는 위협을 완벽하게 예방합니다.

## Instructions

1. **하드코딩 금지 및 로컬 환경 변수 분리**:
   - 코드 파일(`.ts`, `.js`, `.py`) 및 다국어 로컬라이제이션 리소스 파일(`.json`) 내부에는 어떠한 API Key, 프라이빗 토큰, 클라이언트 시크릿 값도 하드코딩하여 저장하지 마십시오.
   - 비밀이 필요한 값은 항상 프로젝트 루트의 `.env` 파일에 선언하고, 코드 내부에서는 `process.env`나 `import.meta.env`를 통하여 주입받아야 합니다.

2. **`.gitignore` 강제 통제**:
   - 작업을 시작하기 전, `.gitignore` 파일에 `.env`, `dist/`, `node_modules/`, `*.log` 등 민감 데이터 및 바이너리가 제외 리스트로 명확하게 기입되어 있는지 확인하십시오.
   - 에이전트는 실수로라도 `.env` 파일 혹은 비밀 정보가 담긴 scratch 텍스트 파일을 Git 스테이징 영역에 포함하는 `git add .env` 명령을 기동해서는 안 됩니다.

3. **스테이징 변경 사항 검사**:
   - `git commit`을 제출하기 전, `git diff --cached`를 통해 기밀 데이터나 암호문 양식의 문자열이 코드 수정본에 누출되었는지 최종 정적 검사를 자율적으로 수행하십시오.
   - 누출 흔적 발견 시, 즉각 해당 파일의 수정을 중단하고 커밋 대상을 리셋(`git restore --staged`)하십시오.
