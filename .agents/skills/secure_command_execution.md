# Skill: Secure Command Execution

## Objective
DevOps 에이전트가 로컬 시스템에서 셸 명령어를 실행할 때, 임의 코드 실행(RCE) 및 불필요한 시스템 리소스 접근을 완벽히 차단하고 통제된 권한 하에 작업을 구동합니다.

## Instructions

1. **최소 권한 원칙 (Least Privilege)**:
   - 일반 사용자 권한 범위 내에서 동작 가능한 명령어만 실행하십시오.
   - 관리자/루트 권한 상승 명령어(`runas`, `sudo` 등)는 사용하지 마십시오. 필요한 경우 작업을 일단 중단하고 사용자에게 상세 사유를 밝힌 뒤 승인을 받아야 합니다.

2. **비인가 네트워크 유출 차단**:
   - `curl`, `wget`, `ssh`, `ftp` 등의 네트워크 데이터 전송 도구를 사용하여 코드베이스 내부 파일이나 `.env`를 외부 서버로 업로드하는 시도를 엄격히 금지합니다.
   - 모든 외부 다운로드는 공인된 패키지 매니저(`npm`, `pip`)의 오피셜 레포지토리를 통해서만 안전하게 이루어져야 합니다.

3. **명령어 입력값 검증 (Command Injection 방지)**:
   - 파일 명칭이나 변수를 셸 매개변수로 결합할 때, 세미콜론(`;`), 앰퍼샌드(`&`), 파이프라인(`|`) 등 다중 명령어를 유도할 수 있는 특수문자가 포함되어 있는지 사전 필터링하십시오.
   - 윈도우 파워셸 환경에서 임의 스크립트 실행 제한 정책(`Set-ExecutionPolicy`)을 우회하거나 낮추는 명령어를 기동하지 마십시오.

4. **로그 관리 및 가시성**:
   - 백그라운드 태스크나 실행 명령어의 아웃풋 로그에 민감한 API Key나 Credential 정보가 노출되지 않도록 마스킹 처리를 필히 수행하십시오.
