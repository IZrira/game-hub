# Astryx 참고 UI 개선 제안

- 작성일: 2026-11-11
- 근거: Astryx 디자인 문서 7개(공간 위계, 글자 위계, 깊이, 모양 관계, 조작 리듬, 색 강조, 모바일 글자)와 운영 사이트 측정(헤드리스 Chrome, 홈·HSR 아케론 상세·세팅 공략·추천 파티, 1440×900·390×844)
- 초안: 운영 화면에 CSS만 임시로 넣어 찍은 전·후 캡처(로컬 `.tmp/astryx-drafts/`, Git 제외)
- 진행 상태 표기: `[ ]` 대기, `[?]` 사용자 결정 대기, `[x]` 완료

## 요약

Astryx 문서는 구체적인 수치보다 원칙 위주다(대부분 초안 단계). 그래서 그대로 옮길 값은 적고, 우리 화면의 어긋난 곳을 찾는 기준으로 쓸 수 있다. 측정해 보니 적용할 만한 곳은 5가지다.

1. 헤더 조작 요소 높이 통일 — 초안 있음
2. 요약 카드의 왼쪽 세로줄 제거, 간격과 구분선으로 묶기 — 초안 있음
3. 공략 화면 모서리 값 정리, 카드 안 카드 줄이기 — 초안 있음
4. 모바일 검색 입력 글자 16px — 초안 있음(겉보기 차이 작음)
5. 글자 크기 역할 정리 — 범위가 커서 초안 없음

해당 없음: 오른쪽→왼쪽 언어 배치, AI 작업 상태, 목록 순서 바꾸기 문서는 이 사이트에 쓸 곳이 없다.

## 1. 헤더 조작 요소 높이 통일 — [x] 2026-11-11

- Astryx 원칙: 한 줄에 놓인 조작 요소는 같은 높이와 기준선을 쓴다. 겉모양이 작아도 누를 수 있는 영역은 충분해야 한다(조작 리듬).
- 현재(데스크톱): 홈 16px, 통합 검색 35px, 언어 26px, 앱 26px, 로그인 33px. "홈"은 글자 크기만큼만 눌린다.
- 제안: 모두 높이 36px, 좌우 여백 12px(로그인 16px), 모서리 10px. 글자 크기와 색은 그대로다.
- 초안: `1-header-rhythm-before.png`, `1-header-rhythm-after.png`(노란 점선이 누를 수 있는 영역)
- 파일: `common-hub/components/Navbar.tsx`

## 2. 요약 카드 왼쪽 세로줄 제거 — [x] 2026-11-11

- Astryx 원칙: 둥근 표면에 굵은 한쪽 테두리를 붙이지 않는다(모양 관계). 묶음은 테두리보다 간격과 정렬로 먼저 나타낸다(공간 위계).
- 현재: 세팅 공략 "추천 세팅 한눈에 보기"의 항목마다 왼쪽에 보라 세로줄이 있다. impeccable 디자인 검사도 같은 곳(`guide-layout.css` 7줄)을 지적했다. 장비 묶음과 주옵션 묶음 사이 간격이 항목 사이 간격과 같아서 두 묶음이 구분되지 않는다.
- 제안: 세로줄을 지우고 항목 이름을 회색 작은 글자로 둔다. 장비 묶음과 주옵션 사이에 얇은 구분선과 더 넓은 간격을 둔다. 장비 이름이 줄바꿈될 때 단어 중간에서 끊기지 않게 한다(`word-break: keep-all`).
- 함께 볼 곳: 캐릭터 상세의 인용문·소개 문단에도 왼쪽 세로줄이 4곳 있다. 같은 기준으로 정리할지 함께 정한다.
- 초안: `2-guide-summary-before.png`, `2-guide-summary-after.png`(데스크톱)
- 파일: `common-hub/components/guides/guide-layout.css`

## 3. 공략 화면 모서리 정리와 카드 안 카드 줄이기 — [x] 2026-11-11

- Astryx 원칙: 모서리 값은 역할(바깥 표면, 안쪽 표면, 조작 요소, 작은 표시)에 따라 정하고, 안쪽 모서리는 바깥과 나란해야 한다(모양 관계). 공간으로 묶을 수 있으면 상자를 하나 더 두지 않는다(공간 위계).
- 현재: 세팅 공략 한 화면에 모서리 값이 12종(4·6·7·8·9·10·12·14·16·18·20·22px)이다. 테두리 있는 표면 48개 중 22개가 다른 테두리 표면 안에 있다. 추천 광추 2순위 이하도 1순위와 같은 무게의 상자다.
- 제안
  - 모서리 4단계: 바깥 표면 16px, 안쪽 카드 12px, 버튼·이미지 틀 8px, 작은 표시 6px.
  - 장비 목록: 1순위만 강조 테두리 카드로 두고, 2순위 이하는 상자 없이 구분선으로 나눈다.
- 초안: `3-guide-shapes-before.png`, `3-guide-shapes-after.png`(모바일)
- 파일: `common-hub/components/guides/guide-layout.css`. 같은 클래스를 쓰는 HSR·WW·NTE 공략에 함께 적용된다.

## 4. 모바일 검색 입력 16px — [x] 2026-11-11

- Astryx 원칙: 터치 기기에서 입력란 글자는 16px 이상이어야 한다. iOS Safari는 16px보다 작은 입력란을 누르면 화면을 자동으로 확대한다(모바일 글자).
- 현재: 추천 파티 검색 입력이 모바일에서 14px이다. 아이폰에서 검색창을 누르면 화면이 확대되고, 사용자가 직접 다시 줄여야 한다.
- 제안: 모바일(`sm` 미만)에서만 입력란 글자를 16px로 한다. 데스크톱은 그대로다. 사이트 전체 입력란(통합 검색, 댓글 등)을 함께 확인한다.
- 초안: `4-party-search-before.png`, `4-party-search-after.png`. 헤드리스 Chrome으로는 iOS 확대 동작을 재현할 수 없어 글자 크기 차이만 보인다.

## 5. 글자 크기 역할 정리 — [x] 2026-11-11

- Astryx 원칙: 글자는 크기가 아니라 역할(페이지 제목, 구역 제목, 본문, 라벨, 보조 글)로 고르고, 이웃한 역할은 눈에 띄게 달라야 한다(글자 위계).
- 현재: 캐릭터 상세 한 화면에 글자 크기가 12종(11·12·13·14·16·17·18·20·24·30·48·100px)이다. 13px와 14px, 17px와 18px처럼 구분이 거의 안 되는 크기가 섞여 있다.
- 제안: `DESIGN.md`에 역할별 크기 5~6단계를 정하고, 캐릭터 상세부터 하나씩 맞춘다. 화면 여러 곳이 바뀌므로 별도 작업으로 하고 초안은 그때 만든다.

## 적용 순서 제안

- 바로 해도 되는 것: 4(버그에 가까움), 1(헤더 한 파일)
- 결정이 필요한 것: 2와 3(공략 화면 첫인상이 바뀜), 5(범위 큼)
- 검증: `npm run typecheck`, 빌드(Notion 동기화 없음), 테스트, `npm run ui:audit`, 전·후 캡처 비교

## 적용 기록 (2026-11-11)

- 1: 데스크톱 헤더의 홈·통합 검색·언어·앱·로그인(로그인 상태의 사용자 표시·로그아웃, 관리자 링크 포함)을 높이 36px, 모서리 8px로 맞췄다. 홈 링크에 좌우 여백과 hover 배경을 줘서 누를 수 있는 영역이 생겼고, 늘어난 여백만큼 항목 간격을 `gap-6 lg:gap-8`에서 `gap-4 lg:gap-6`으로 줄였다. 측정: 모든 조작 36px, 데스크톱 24px 미만 조작 0(전: 홈 12×16px).
- 2: 요약 항목의 보라 세로줄을 지우고 `word-break: keep-all`로 단어 중간 줄바꿈을 막았다. 이미지 없는 수치 목록(HSR 주옵션, NTE 기본 목표)은 `guide-summary-stats`로 표시해 모바일과 한 줄 전체를 차지할 때만 위에 구분선을 둔다. 항목 세로 간격은 12px에서 20px로 늘렸다.
- 3: 공략 CSS 모서리를 16(바깥 표면)·12(안쪽 카드)·8(버튼·이미지 틀)·6(작은 표시)px 4단계로 정리했다(측정: 12종 → 4종, 원형 제외). 장비 목록은 1순위만 카드로 두고 2순위부터는 구분선 행으로 바꿨다. 링크 행은 hover 때 이름에 밑줄이 생긴다.
- 4: 터치 기기(`pointer: coarse`)이면서 너비 1024px 미만이면 글자 입력란·선택 상자·편집 영역을 최소 16px로 한다(`common-hub/index.css`). 측정: 추천 파티 검색 14px → 16px.
- 확인: HSR 아케론·NTE 잔홍 공략(모바일·데스크톱), 헤더, 추천 파티를 로컬 빌드로 캡처했다. `ui:audit` 4개 화면 × 2개 크기에서 대비 미달·이름 없음·제목 건너뜀·24px 미만 조작 모두 0이다. 실제 아이폰에서의 확대 방지는 확인하지 못했다.

## 후속 정리 (2026-11-11)

- 글자 크기: `DESIGN.md`에 역할 단계(11·12·14·16·18·20·24·30px 이상)를 적고, 공개 화면의 13·15·17px와 8·9·10px를 이웃 역할로 옮겼다(스킬 설명 17→16px, 세트 효과 13→14px, 아이콘 수량 13→12px, 작은 표시 8~10→11px). 관리자 화면은 그대로다.
- 왼쪽 세로줄: 캐릭터·무기·아크 상세의 구역 제목과 설명 문단, 마크다운 제목, 블로그·약관 첫 문단에서 지웠다. 댓글 답글 선, 애니모 진화 트리 선처럼 구조를 나타내는 선과 무기 등급 색 표시는 남겼다. 마크다운 인용문은 얇은 회색 선으로 바꿨다.
- 홈 게임 카드의 기호(✦ ◈ ◇ ●)를 선 아이콘(기차, 물결, 건물, 발자국)으로 바꿨다.
- 모서리: 공개 화면의 `rounded-[숫자px]` 192곳을 14px 이하 `rounded-xl`, 20px 이하 `rounded-2xl`, 그 이상 `rounded-3xl`로 바꿨다. 100px 장식 모양 2곳은 남겼다.
- 모션: `transition-all` 224곳(CSS 2곳 포함)을 `transition`으로 바꾸고, 접힘 영역 8곳은 `transition-[max-height,opacity,padding]`, 막대 길이 2곳은 `transition-[width,background-color]`로 지정했다.
- 공략 구역 번호 상자(01·02…)는 초안만 만들었다(`.tmp/astryx-drafts/5-section-number-*`). 캐릭터 상세에도 같은 번호 상자가 있어 함께 정한다.
