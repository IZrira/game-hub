## 4. 관찰 기준

- 점검 주기: 주 1회(`npm run seo:check`, 사용자 요청 시 실행). 자동 예약은 만들지 않는다.
- 보는 값
  - 주별 노출과 클릭
  - 사이트맵 URL 중 노출 있는 URL 수
  - 색인됨·발견됨-미색인 수(Search Console 화면, 사용자 로그인 후 읽기)
- 회복 신호: "발견됨-미색인"이 줄고, 성과 그룹의 노출이 다시 하루 100을 넘는 것.
- 4주 동안 변화가 없으면 진단을 다시 한다. 그때 Search Console 화면에서 직접 조치를 다시 확인한다.
- 사이트 품질 재평가는 보통 몇 주에서 몇 달이 걸린다. 회복 여부와 시점은 보장하지 않는다.

## 5. 하지 않는 것

- 정상 URL의 색인 요청 반복, 사이트맵 반복 제출
- 글자 수를 채우기 위한 문장 늘리기, 얇은 페이지 대량 생성
- 화면에 없는 구조화 데이터(FAQ·평점·리뷰) 추가
- 사용자 결정 없이 기존 공개 URL 삭제나 리디렉션
