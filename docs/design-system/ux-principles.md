# Rira Game Hub UX 상태·검증 체크리스트

이 문서는 루트 `DESIGN.md`의 UX 정책을 구현할 때 사용하는 체크리스트다. 충돌 시 `DESIGN.md`가 우선한다.

## Default

- 페이지 제목과 현재 게임을 바로 알 수 있는가
- 가장 중요한 행동 또는 정보가 첫 화면에 있는가
- 같은 정보가 카드와 링크로 중복되지 않는가
- 설명 콘텐츠가 불필요한 카드 안에 갇혀 있지 않은가
- 게임별 대표 정보 우선순위가 반영됐는가

## Loading

- 기존 레이아웃과 비슷한 크기의 fallback 또는 스켈레톤을 사용하는가
- 콘텐츠 로딩 중 레이아웃이 크게 움직이지 않는가
- 실제 상태를 설명하는 짧은 문구를 사용하는가
- 의미 없는 점멸, 시스템 상태 또는 가짜 동기화 문구가 없는가

## Empty

- 무엇이 비어 있는지 한국어로 알 수 있는가
- 필터 초기화, 다른 메뉴 이동 또는 등록 등 다음 행동을 제공하는가
- 빈 카드를 여러 개 유지해 화면을 채우지 않는가

## Error

- 사용자가 이해할 수 있는 오류 문구가 있는가
- 다시 시도하거나 이전 화면으로 돌아갈 수 있는가
- 이미지 오류가 재귀 요청을 만들지 않는가
- 오류가 나도 페이지의 나머지 탐색이 가능한가

## Success

- 저장·복사·동기화 결과가 분명한가
- 성공 메시지가 핵심 콘텐츠를 가리지 않는가
- 자동 저장은 저장 중, 완료와 실패 상태를 구분하는가

## Interaction

- 링크와 버튼의 역할이 시각적으로 구분되는가
- hover가 없는 터치 환경에서도 의미를 이해할 수 있는가
- 확대 효과 없이도 클릭 가능 여부가 드러나는가
- 비활성 상태와 선택 상태를 색상 이외의 수단으로도 구분하는가
- reduced-motion 환경에서 기능이 유지되는가

## Accessibility

- 의미 있는 HTML 요소를 사용했는가
- 키보드만으로 순서대로 이동하고 조작할 수 있는가
- 포커스 표시가 보이는가
- 아이콘 단독 버튼에 접근 가능한 이름이 있는가
- 이미지 `alt`가 용도에 맞는가
- 텍스트 대비가 WCAG AA 수준인가

## Responsive

- 320px 수준에서 가로 넘침과 잘림이 없는가
- 모바일 읽기 순서가 정보 우선순위와 일치하는가
- 고정 높이로 번역문이나 긴 이름이 잘리지 않는가
- 필터, 탭과 표를 터치로 사용할 수 있는가
