# 공지사항 작성 및 버전 관리 가이드 (Notice Policy)

이 문서는 RIRA ARCHIVE의 공지사항 작성 시 준수해야 할 가이드라인과 버전 표기 규칙을 정의합니다.

## 1. 버전 표기 규칙
공지사항 작성 시 인게임 버전과 웹사이트(시스템) 버전이 다름에 유의해야 합니다.

*   **인게임 버전 (In-game Version)**: 해당 게임의 실제 패치 버전을 의미합니다. 
    *   현재 HSR 기준: **v4.0 ~ v4.2**
*   **웹사이트 버전 (Website Version)**: RIRA ARCHIVE 웹 사이트 자체의 시스템 업데이트 버전을 의미합니다. 
    *   현재 기준: **v1.0**

> [!IMPORTANT]
> 공지사항의 `version` 필드나 내용 상의 버전 언급 시, 사용자가 혼동하지 않도록 어떤 버전인지 명확히 구분하여 기재합니다. 웹사이트 기능 업데이트는 **v1.0** 계열로 표기합니다.

## 2. 공지사항 작성 원칙
*   **사용자 중심 기록**: 공지사항에는 관리자 전용 기능 개선(어드민 대시보드 탭 이동, 관리 도구 추가 등) 내역은 제외합니다.
*   **사용자 체감 내역 우선**: 데이터 오류 수정, 이미지 에셋 복구, 신규 캐릭터/광추 데이터 추가 등 사용자가 직접 이용하는 콘텐츠의 변경 사항만 기록합니다.
*   **분류(Category) 기준**:
    *   `Update`: 게임 콘텐츠 데이터 추가 및 정규화
    *   `Event`: 이벤트 관련 안내
    *   `System`: 웹사이트 시스템 안정화 및 UI/UX 개선
    *   `Notice`: 기타 일반 공지사항
