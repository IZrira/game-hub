# GF2 용어 사전

GF2 PDF 및 Notion 캐릭터 데이터 입력 시 먼저 조회하는 재사용 기준 문서다. 사이트 런타임 데이터나 자동 동기화 프로그램은 아니다.

## 조회·입력 규칙

1. 용어 이름의 `_`를 공백으로 바꾸고 앞뒤 공백 및 연속 공백을 정리한 뒤 제목으로 찾는다. 예: `화끈한_공세Ⅱ` → `화끈한 공세Ⅱ`.
2. `Ⅱ` 같은 단계 표기는 보존한다. 다른 단계의 용어를 같은 효과로 합치지 않는다.
3. 같은 이름과 같은 효과가 확인되면 아래 효과를 재사용하며 중복 항목을 만들지 않는다. 원문 정의가 없는 PDF도 이 사전의 동일 이름 정의를 사용할 수 있다. 다만 해당 캐릭터가 실제로 참조하는 용어에만 적용한다.
4. 새 자료에서 같은 이름의 수치·조건·지속 시간·대상이 다르면 기존 정의를 덮어쓰지 않는다. 캐릭터·서버·버전별 차이를 기록하고 사용자에게 충돌을 알린 뒤 해당 맥락에 맞는 정의를 선택한다.
5. 확인하지 못한 정의는 추측하지 않는다. 사용자 제공 주석이나 확인 가능한 기준 자료로 검증한 뒤 추가한다.
6. Notion `용어` 속성에는 `용어 이름 : 효과` 형태로 넣고 항목 사이를 빈 줄로 구분한다. 각주 번호와 상호 참조 번호는 데이터에 넣지 않는다.
7. 다른 캐릭터에서 재사용하면 해당 항목의 확인 캐릭터 목록을 갱신한다. 다른 게임의 동명 용어에는 이 사전을 적용하지 않는다.
8. 용어가 사전에 있다는 이유로 미출시 캐릭터나 중국 서버 전용 스킬을 한국 서버 캐릭터 데이터에 추가하지 않는다. 스킬의 서버 적용 여부는 별도 검증한다.
9. 캡처는 `캐릭터명 용어.png` 또는 `캐릭터명 용어1.png`, `캐릭터명 용어2.png` 형식이다. 분할 파일은 숫자순으로 모두 확인하며 일부만 읽고 해당 캐릭터를 완료 처리하지 않는다.
10. `지속 치유 I & II`처럼 묶인 표기는 단계마다 이름과 효과를 분리한다. 로마 숫자는 제목에서 `Ⅰ`, `Ⅱ`, `Ⅲ`로 통일하되 단계 자체를 바꾸지 않는다. 수치가 단계별로 확인되지 않으면 추측하지 않는다.
11. 캡처에 적힌 중복 불가·발동 제외 조건도 보존한다. 각주 번호는 제외하지만 각주 내용은 누락하지 않는다.

## GF2 캐릭터 입력 시 함께 적용할 형식

- `결합도 보상`은 다음 네 줄로 입력한다. 이미지 연결은 별도의 사이트 구현 작업이며 이 문서 작성만으로 적용되지 않는다.

```text
결약 보상 프로필
결약 보상 테두리
결약 보상 무기 장식
결약 보상 무기 스킨
```

- `스킨`에는 해당 캐릭터의 확인된 스킨 제목만 줄바꿈으로 입력한다. 설명, 가격, 획득 방법은 섞지 않는다. 한국 서버 미출시 항목은 별도로 확인한다.
- 사용자가 고친 이름과 기존 로컬 데이터는 임의로 되돌리지 않는다. 충돌은 비교 후 처리한다.
- Notion 편집과 Notion → 웹사이트 동기화는 구분한다. 웹사이트 동기화는 명시적으로 요청받은 경우에만 실행한다.
