# Search Console 소유권 인증 유지

2026-10-15. URL 접두어 속성 https://riragamehub.com/의 HTML 태그 인증을 사용한다.

- 사용자가 제공한 공개 google-site-verification 태그를 루트 index.html의 head에 직접 유지한다. 이 값은 공개 소유권 확인용 식별자이며 API 비밀 키가 아니다.
- React 실행이나 선택적 빌드 환경변수만으로 태그를 생성하지 않는다. Google이 처음 받는 홈페이지 HTML에 있어야 한다.
- 기존 다른 소유자의 인증값을 임의로 제거하거나 교체하지 않는다. 변경은 사용자 확인 후 진행한다.
- scripts/audit-prerender-seo.js가 원본과 최종 dist/index.html의 head를 비교한다. 태그가 누락되면 빌드가 실패한다. 본문이나 스크립트 문자열의 태그는 인증으로 인정하지 않는다.
- 배포 후 운영 홈을 HTTP로 요청해 head 내 정확한 태그를 대조한다. 검사 통과와 Google의 실제 소유권 확인 완료는 구분한다.
- 사용자는 Search Console에서 HTML 태그 방식의 확인을 다시 실행한다. 에이전트가 소유권 확인 버튼을 대신 누르거나 DNS·계정 권한을 임의로 변경하지 않는다.

## 진단 이력

운영 홈 초기 HTML에 인증 메타 태그가 없었고, 기존 google92275b89a51149d4.html 파일 주소는 확장자 제거 308 후 404가 발생했다. 이번 수정은 사용자 제공 HTML 태그를 복구하며 기존 파일 방식·DNS·계정 권한은 변경하지 않는다. 파일 방식 복구가 필요하면 별도 범위로 처리한다.
