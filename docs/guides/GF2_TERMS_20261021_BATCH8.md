# GF2 용어 캡처 8차 정리

사용자 제공 `캐릭터 스킬 상세 용어` 폴더의 분할 PNG를 숫자순으로 직접 확인했다. `_`는 공백으로 바꾸고 각주 번호를 제외했다. 아래 정의는 Notion 기존 캐릭터의 `용어` 속성에 입력할 기준이며, 웹사이트 동기화 데이터가 아니다. Notion 반영 결과는 진행 보고서에 별도 기록한다.

## 헬렌

출처: `헬렌 용어1.png`, `헬렌 용어2.png`. 19개.

- 감싸기 : 자신이 헬렌 주위 반경 6칸 안에서 피해를 받을 때, 헬렌이 원시 피해의 100%를 대신 받는다. 정화 불가 버프.
- 프로스트 드라이브 : 1스택마다 자신이 주는 빙결 피해 +20%, 최대 +60%. 정화 불가 버프.
- 차징 엣지 : 1스택마다, 자신의 치명률과 일반공격으로 주는 빙결 피해 +10%. 중첩 가능, 공격 후 소모. 정화 불가.
- 찬란한 모성 : 자신의 방어력은 최소 100%를 유지한다. 자신의 체력이 30% 미만이 될 때 해제. 정화 불가.
- 서리 보호막 : 보호막, 서리 보호막이 깨질 때 깨뜨린 자에게 결빙 효과를 1턴간 부여한다. 빙결계 버프, 정화 불가.
- 보호막 : 일정량의 피해를 흡수한다. 보호막은 서로 중첩되지 않지만 덮어씌울 수 있다. 후에 부여된 보호막의 지속 턴 수 또는 흡수량이 기존보다 높을 경우 덮어씌운다. 보호막은 서리 보호막, 원금 보장 등을 포함한다.
- 서리밭 : 이 구역에서 행동을 마친 적 유닛에게 응고 효과를 2턴 동안 부여한다. 구역 안의 적에게 빙결 약점을 부여한다. 빙결계 타일.
- 응고 : 이동력 -1칸. 행동 종료 시 응고를 2스택 가지고 있으면, 결빙 효과로 변하고 1턴간 지속된다. 최대 중첩 2스택. 빙결 이동 디버프.
- 결빙 : 이동할 수 없게 된다. 자신의 액티브 스킬로 위치가 변하지 않는다. 빙결계 이동 디버프.
- 추가 스킬 : 이동을 제외한 기타 지시를 수행할 수 있다.
- 추가 이동 : 1회 이동할 수 있지만 다른 지시를 사용할 수 없다.
- 도피 : 컨트롤 불가. 스스로 부여자에게서 멀리 이동한다. 부여자가 쓰러지면 해제된다.
- 기절 : 행동 불가.
- 도발 : 컨트롤 불가. 강제로 일반 공격을 사용하여 부여자를 공격한다. 부여자가 쓰러지면 해제된다.
- 유도 : 컨트롤 불가. 스스로 부여자에게 접근하게 된다. 부여자가 쓰러지면 해제된다.
- 치명피해 상승Ⅱ : 치명피해 +20%. 버프.
- 공격 상승Ⅲ : 공격력 +20%. 버프.
- 방어 상승Ⅲ : 방어력 +40%. 버프.
- 엄호 : 안정 보호를 받아 자신이 받는 안정 피해 -2점. 안정 피해를 받을 때마다 1스택 소모, 최대 중첩 3스택. 버프.

## 바스티

출처: `바스티 용어1.png`, `바스티 용어2.png`. 19개.

- 독장 : 타일 위 적 유닛에게 산성 약점을 부여한다. 이 타일 위에서 행동을 마친 적 유닛에게 부여자 공격력 50% 고정 피해를 주고, 불안정Ⅰ 효과를 2턴간 부여한다. 산성계 타일.
- 불안정Ⅰ : 받는 안정 피해 +1점. 방어 디버프.
- 독소 고리 : 받는 산성 피해 +25%. 산성계 방어 디버프.
- 기절 : 행동 불가.
- 유도 : 컨트롤 불가. 스스로 부여자에게 접근하게 된다. 부여자가 쓰러지면 해제된다.
- 도피 : 컨트롤 불가. 스스로 부여자에게서 멀리 이동한다. 부여자가 쓰러지면 해제된다.
- 도발 : 컨트롤 불가. 강제로 일반 공격을 사용하여 부여자를 공격한다. 부여자가 쓰러지면 해제된다.
- 앙금 : 보유자가 공격을 하기 전 바스티 주위 반경 8칸 안에 있을 경우, 이 효과를 1스택 소모하여 바스티가 특수 지원을 가하여, 보유자에게 공격력 100% 범위 산성 피해를 준다. 최대 중첩 1스택. 산성계 디버프, 정화 불가.
- 서방성 의존 : 디버프가 정화되지 않는다. 정화를 1회 방지할 때마다 1스택 소모. 정화 불가 중성 효과.
- 휘감긴 메롱 : 받는 산성 피해 +15%, 산성 피해를 받을 때 공격자는 이번 피해의 15%만큼 체력을 회복한다. 정화 불가 산성계 디버프.
- 동료의 휘장 : 주는 피해 +15%. 행동 종료 시 안정 지수를 1점 회복한다. 정화 불가.
- 기능성 드링크 : 1스택마다 자신과 소환물이 주는 피해 +12%, 자신이 주는 치료 효과 +5%, 최대 중첩 5스택. 정화 불가 버프.

- 지속 치유Ⅱ : 행동 종료 시 자신의 체력상한 20%만큼 회복한다. 버프.
- 방어 상승Ⅲ : 방어력 +40%. 버프.

- 왜곡된 감정 : 산성 피해를 받을 때, 보유자가 적의 산성계 타일 위에 있을 경우 받는 피해 +30%, 받는 치명피해 +15%. 정화 불가 산성계 방어 디버프.
