# 티어 업데이트 템플릿

새로운 캐릭터를 추가하거나 기존 캐릭터의 티어를 변경할 때 아래 서식을 복사하여 사용하세요.

## 1. 신규 캐릭터 추가 서식
```json
{ 
  "id": "char_캐릭터이름", 
  "folderName": "캐릭터이름", 
  "role": "역할(메인 딜러/서브 딜러/서포터/유지력)", 
  "name": "캐릭터이름", 
  "change": "new" 
}
```

## 3. 등급 기준 (참고)
- **OP**: 메타를 지배하는 필수 캐릭터
- **SS**: 매우 강력하며 범용성이 높은 캐릭터
- **S+/S**: 특정 환경에서 최상위 성능을 발휘하는 캐릭터
- **A/B**: 무난하게 사용 가능한 캐릭터
- **C 이하**: 특정 조합이나 상황에서만 제한적으로 사용되는 캐릭터

## 업데이트 가이드라인
1. **상태 관리**: 새로운 캐릭터 추가 시 `"change": "new"`를 사용하고, 다음 티어 업데이트 시에는 `"change": "stay"`로 변경하여 신규 표시를 제거합니다.
2. **문서 동기화**: `tiers.ts` 수정 후 반드시 `docs/tiers/current_tiers_summary.md` 파일도 함께 업데이트하여 최신 상태를 유지합니다.
