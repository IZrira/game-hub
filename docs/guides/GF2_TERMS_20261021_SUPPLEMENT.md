## 센타우레이시

- 주석 23, 60: 사용자가 무시해도 된다고 명시했다. 추가 입력·연결 확인 대상에서 제외한다. 과거 기록은 당시 상태로 남기되 현재 미완료 항목으로 집계하지 않는다.
- 주석 63: 사용자 제공 `센타우레이시 용어3.png`의 19종 후보를 아래와 같이 분리했다. 정식 버프 고유명은 캡처에 없으므로 임의로 이름이나 단계 번호를 만들지 않는다.
- 아래 `무작위 버프 후보`는 설명용 제목이다. 캡처에 없는 연결 스킬이나 발동 조건은 덧붙이지 않는다. Notion 기존 용어를 보존하고 별도 설명 항목으로 추가한다.

## 소프

`열상 충격`의 기존 개요를 [이질 융합 공통 사전](./GF2_HETEROGENEOUS_FUSION.md)의 연소+빙결 일반·Ⅱ·Ⅲ 정의로 보완한다. 나머지 기존 용어는 보존한다. 일반 단계의 이름은 `열상 충격`으로 유지하고 Ⅰ을 임의로 붙이지 않는다.

## 공통 이질 융합

속성이 2개 합쳐진 타일의 분류명은 `이질 융합`이다. 파일명 규칙은 `속성 속성 이질 용어`다. 확인된 7개 이미지의 총 21개 단계 정의는 공통 사전에 저장한다. 캐릭터가 실제 참조한 조합만 Notion 캐릭터 용어에 사용하며, 이번 소프 입력에는 연소+빙결 3개 단계만 사용한다.

추가 이미지가 기존 하위 효과의 독립 정의까지 제공한 것은 아니다. 폭연·함몰 등의 고유 효과를 추가로 추정하지 않는다.
