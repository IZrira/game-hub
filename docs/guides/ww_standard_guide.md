# 🌊 명조 (Wuthering Waves) 종합 개발 & 텍스트 포맷팅 표준 가이드 (WW Standard Guide)

> **문서 용도**: Rira Game Hub의 명조 캐릭터 상세 페이지 UI 구조, 데이터 매핑 규칙, 스킬 입력 가이드 작성법(A/B 타입), 텍스트 자동 하이라이트 및 에셋 관리 표준을 정의하는 통합 가이드입니다.

---

## 1. 📌 상세 페이지 섹션 구성 순서 (Fixed Section Layout)

명조 캐릭터 상세 페이지는 다음 10단계 고정 순서로 렌더링됩니다:

1. **프로필 헤더**: 일러스트, 속성, 무기, 성우 정보, 출시 버전
2. **01. 기본 스탯**: 레벨 슬라이더(1~90Lv) 기반 HP, 공격력, 방어력 수치
3. **02. 캐릭터 소개**: 캐릭터 배경 설정 및 요약 소개
4. **03. 캐릭터 프로필 & 성우 정보**: 다국어 명칭 및 성우 매핑 테이블
5. **04. 전투 역할**: 메인 딜러, 서브 딜러, 서포터, 생존 등
6. **05. 육성 재료**: 돌파 재료 및 행적/스킬 재료 (복사 기능 포함)
7. **06. 스킬 정보**: 각 스킬별 상세 설명 및 계수 (조화도 파괴 포함)
8. **07. 스킬 입력 가이드**: 공명 회로 게이지 시각화 및 주요 조작 콤보
9. **08. 공명 체인**: 1~6단계 돌파 효과 (동적 이미지 매핑)
10. **09. 관련 용어**: 캐릭터별 고유 특수 용어 상세 툴팁

## 2. 🎨 속성별 테마 컬러 & 디자인 시스템

UI 및 마크다운 렌더러에서 사용하는 명조 속성별 고유 헥사 색상:

* **인멸 (Havoc)**: `#F472B6` (마젠타 핑크 - 플로로, 칸타렐라 테마)
* **회절 (Spectro)**: `#FBBF24` (회절 노랑)
* **기류 (Aero)**: `#4ADE80` (기류 초록)
* **용융 (Fusion)**: `#FB7185` (용융 빨강)
* **응결 (Glacio)**: `#60A5FA` (응결 파랑)
* **전도 (Electro)**: `#A78BFA` (전도 보라)

## 3. 📝 텍스트 하이라이트 및 포맷팅 규칙

### 3.1. 속성 피해 자동 하이라이트
* 명조의 6가지 속성 키워드 뒤에 **'피해'**가 붙은 경우(예: `인멸 피해`, `기류 피해`) 시스템이 전용 테마 색상을 자동 적용합니다.
* **제외 사항**: `[속성명] 피해 보너스`는 자동 하이라이트에서 제외되어 일반 텍스트 색상을 유지합니다.

### 3.2. 문단 제목 (`**제목**`)
* 스킬 이름이나 주요 카테고리는 `**일반 공격**` 형태로 작성합니다. 시스템이 묵직한 두께(`font-weight: 900`)의 `#a89969` 골드 서브타이틀로 렌더링합니다.

### 3.3. 전투 용어 툴팁 강조 (`==키워드==`)
* 스킬 설명 본문 내에서 특정 메커니즘이나 시스템 용어는 `==용의 승천==` 형태로 감쌉니다.
* 화면에는 기호 없이 노란색(`#fbbf24`) 글로우 하이라이트가 적용되며, 마우스 오버 시 최대 **600px** 너비의 상세 툴팁이 팝업됩니다.

## 4. 🎮 스킬 입력 가이드 표준 템플릿 (A/B 타입)

### 4.1. [A타입] 상세 분석 및 메커니즘 강조형 (예: 복링, 시그리카)
* 복잡한 스택 관리와 여러 단계의 효과 설명이 필요한 캐릭터용.
* **데이터 설정**: `hideGauge: true`를 설정하여 최상단 자동 게이지 이미지를 숨기고, 모든 내용을 `overview` 문자열 필드 하나에 줄바꿈(`\n\n`) 기호와 함께 통합합니다.
* **필수 섹션**: `설명` ➡️ `특수 에너지` ➡️ `메커니즘 설명`

### 4.2. [B타입] 개요 및 직관적 조작형 (예: 알토, 양양, 상리요)
* 메커니즘이 직관적이거나 특정 상태 진입 조건이 명확한 캐릭터용.
* **데이터 설정**: `overview`에는 핵심 개요를, `inputs` 배열에는 개별 조작법(`character.[id].skillInput.inputs.0`)을 나열합니다.

### 4.3. 조작 아이콘 키캡 포맷
* 키보드: `{{KEY_E}}`, `{{KEY_Q}}`, `{{KEY_R}}`, `{{KEY_SHIFT}}`, `{{KEY_SPACE}}`
* 마우스: `{{MOUSE_L}}` (좌클릭), `{{MOUSE_R}}` (우클릭)
* 특수: `{{JUMP}}` (점프)

## 5. 📂 에셋 경로 및 네이밍 표준

* **Base URL**: `https://cdn.jsdelivr.net/gh/IZrira/riragameinfo@main/ww images/`
* **일러스트**: `skills/[폴더명]/[폴더명].webp`
* **공명 회로 게이지**:
  * 단일 게이지: `공명 회로 게이지.webp`
  * 다중 게이지: `공명 회로 게이지1.webp`, `공명 회로 게이지2.webp` (넘버링 필수)
* **공명 체인**: `skills/[폴더명]/공명 체인[1-6].webp`
* **일반 공격**: 파일명은 항상 `일반 공격.webp`로 강제 매핑.
* **조화도 파괴**: 캐릭터별 고유 `조화도 파괴.webp` 에셋 우선 참조.
* **인코딩 표준**: 모든 에셋 경로는 `safeEncodeURIComponent`를 통과하여 NFC/NFD 자소 분리 및 공백 오류를 방지함.
