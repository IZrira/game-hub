# 명조 (Wuthering Waves) 캐릭터 스킬 텍스트 작성 가이드

Rira Game Hub의 명조 캐릭터 스킬 설명 및 본문 텍스트 작성 시 지켜야 할 마크다운(Markdown) 포맷팅 가이드입니다. 
본 가이드에 맞춰 순수 텍스트로 데이터를 작성하면, 시스템이 인게임과 동일한 스타일의 하이라이트 및 이펙트를 자동으로 적용합니다.

---

## 1. 속성 피해 (자동 색상 적용)
명조의 6가지 속성 키워드 뒤에 **'피해'**가 붙은 경우(예: 인멸 피해) 시스템이 자동으로 감지하여 전용 색상을 입혀줍니다.
**※ 주의: '피해 보너스' 등 다른 단어가 포함된 경우 자동으로 적용되지 않으며 일반 텍스트 색상으로 유지됩니다.**

- **기류 피해**: `#4ade80` (연두색)
- **응결 피해**: `#60a5fa` (파란색)
- **전도 피해**: `#a78bfa` (보라색)
- **용융 피해**: `#fb7185` (장미색/분홍)
- **회절 피해**: `#fde047` (밝은 노란색)
- **인멸 피해**: `#F472B6` (마젠타 핑크 - 플로로/칸타렐라 테마)

---

## 2. 툴팁 및 호버 인터페이스
시스템 용어 사전에 등록된 키워드(==키워드==)에 마우스를 올리면 상세 설명 툴팁이 나타납니다.
- **툴팁 너비**: 가독성을 위해 최대 **600px**까지 확장되었습니다.
- **인멸 속성 테마**: 인멸 속성 캐릭터의 경우 페이지 전체 테마가 `#F472B6` 마젠타 핑크로 적용됩니다.

---

## 3. 문단/스킬 제목 (`**제목**`)
텍스트 문단 상단에 스킬 이름이나 주요 카테고리를 제목으로 표시할 때는 양쪽에 `**` 기호를 사용합니다.
시스템은 이를 일반적인 굵은 글씨가 아닌, 묵직한 두께(`font-weight: 900`)가 들어간 색상(`#a89969`) 서브 타이틀 블록으로 렌더링합니다.

*작성 예시:*
> **일반 공격**
> 최대 5단 연속 공격을 가하여 기류 피해를 가한다.

---

## 3. 전투 용어 및 특수 매커니즘 강조 (`==키워드==`)
스킬 설명 본문 내에서 특정 매커니즘(예: 용의 승천, 은신참 등)이나 전투 시스템 용어를 강조하고 싶을 때는 양쪽에 `==` 기호를 사용합니다. 
화면에는 기호 없이 텍스트만 노란색(`#fbbf24`)에 은은한 글로우가 적용되어 깔끔하게 하이라이트 됩니다.

*작성 예시:*
> 강공격 기간 ==일반 공격==을 누를 시 강공격 종료 후 ==용의 승천==이 발동되며 기류 피해를 가한다.

---

## 💡 종합 작성 예제
캐릭터 데이터를 위키나 JSON에 등록할 때 아래와 같이 작성하면 됩니다.

```markdown
스킬 정보

기본 공격
**고독한 창**

**일반 공격**
최대 5단 연속 공격을 가하여 **기류 피해**를 가한다.

**강공격**
스태미나를 소모하여 돌진 공격을 가하여 **기류 피해**를 가한다.

**강공격·용의 승천**
==강공격== 기간 ==일반 공격==을 누를 시 ==강공격== 종료 후 ==용의 승천==이 발동되며 **기류 피해**를 가한다.

**강공격·은신참**
==강공격== 기간 ==일반 공격==을 뗄 시, ==강공격== 종료 후 ==은신참==을 발동하여 **기류 피해**를 가한다.

**공중 공격**
스태미나을 소모하여 공중 낙하 공격을 하여 **기류 피해**를 가한다.
==낙하 공격== 후 일정 시간 내에 ==일반 공격==을 짧게 누르면 목표에게 추가 공격을 가하여 **기류 피해**를 입힌다.

**공중 공격·청룡의 낙하**
강공격 ==용의 승천== 또는 공중에서 공명 스킬 ==돌진의 창== 발동 후의 일정 시간 내에 공중 공격을 가하여 **기류 피해**를 입힐 수 있다.

**회피 반격**
==회피== 성공 후 일정 기간 내에 ==일반 공격==을 짧게 누르면 목표에 공격을 가하여 **기류 피해**를 입힌다.
```

## 4. 캐릭터 상세 페이지 섹션 구성 순서
상세 페이지의 정보는 다음의 고정된 번호와 순서로 구성됩니다.

- **01~03**: 캐릭터 프로필, 능력치, 소개 및 성우 정보
- **04. 전투 역할**: 포지션 및 주요 역할
- **05. 육성 재료**: 돌파 및 행적(스킬) 업그레이드 재료
- **06. 스킬 정보**: 액티브/패시브 스킬 상세 정보
- **07. 공명 체인**: 돌파 단계별 효과 (1~6단계)

---

### 스킬 및 공명 체인 이미지
모든 스킬과 공명 체인 이미지는 동일한 경로 베이스를 공유합니다.
- **Base URL**: `https://cdn.jsdelivr.net/gh/IZrira/riragameinfo@main/ww images/skills/[캐릭터 폴더명]/`
- **공명 회로 게이지**: 
    - 게이지가 1개인 경우: `공명 회로 게이지.webp`
    - 게이지가 여러 개인 경우: `공명 회로 게이지1.webp`, `공명 회로 게이지2.webp` 등 (넘버링 필수)
- **공명 체인 파일명**: `공명 체인1.webp`, `공명 체인2.webp`, ..., `공명 체인6.webp` (띄어쓰기 주의)

### 스킬 입력 가이드 조작 아이콘
본문 내에서 특정 키나 마우스 조작을 아이콘으로 표시하려면 다음 규격을 사용합니다:
- **키보드**: `{{KEY_E}}`, `{{KEY_Q}}`, `{{KEY_SPACE}}` 등
- **마우스**: `{{MOUSE_L}}` (좌클릭), `{{MOUSE_R}}` (우클릭)
- **특수**: `{{JUMP}}` (점프 아이콘)

### 이미지 에셋 관리
- **공명 회로 게이지**: 
    - 게이지가 1개인 경우: `공명 회로 게이지.webp`
    - 게이지가 여러 개인 경우: `공명 회로 게이지1.webp`, `공명 회로 게이지2.webp` 등 (넘버링 필수)
    - **게이지 이미지가 없는 경우**: 데이터 설정에서 `hideGauge: true`를 적용하여 영역을 숨길 수 있습니다.
- **공명 체인 파일명**: `공명 체인1.webp`, `공명 체인2.webp`, ..., `공명 체인6.webp` (띄어쓰기 주의)
- **전투 역할 아이콘**: 
    - **Base URL**: `https://cdn.jsdelivr.net/gh/IZrira/riragameinfo@main/ww images/common/position/`
    - **파일명**: `[역할명].webp` (예: 공명 해방 피해.webp)
