# 명조 (Wuthering Waves) 캐릭터 상세 페이지 표준 가이드

본 문서는 Rira Game Hub의 명조 캐릭터 상세 페이지 UI 구조 및 데이터 매핑 표준을 정의합니다.

---

## 1. 섹션 순서 및 구성
상세 페이지는 다음 순서로 고정되어 렌더링됩니다:

1. **프로필 헤더**: 일러스트, 속성, 무기, 성우 정보, 버전 정보
2. **01. 기본 스탯**: 레벨 슬라이더 기반 HP/공격력/방어력 수치
3. **02. 캐릭터 소개**: 캐릭터 배경 설정 및 간단 요약
4. **03. 캐릭터 프로필 & 성우 정보**: (상세 테이블)
5. **04. 전투 역할**: 메인 딜러, 치료 등 캐릭터 포지셔닝
6. **05. 육성 재료**: 돌파 재료 및 행적 재료 리스트 (복사 기능 포함)
7. **06. 스킬 정보**: 각 스킬별 상세 설명 및 계수 (조화도 파괴 포함)
8. **07. 스킬 입력 가이드**: 공명 회로 게이지 시각화 및 주요 조작 콤보
9. **08. 공명 체인**: 돌파 단계별 효과 (동적 이미지 매핑)
10. **09. 관련 용어**: 캐릭터별 특수 용어 상세 설명

## 3. 데이터 매핑 규칙
### 3.1. 이미지 에셋 경로
- **일러스트**: `riragameinfo/ww images/skills/[폴더명]/[폴더명].webp`
- **공명 회로 게이지**: 
    - 단일 게이지: `공명 회로 게이지.webp`
    - 다중 게이지: `공명 회로 게이지1.webp`, `공명 회로 게이지2.webp` (넘버링 적용)
- **공명 체인**: `riragameinfo/ww images/skills/[폴더명]/공명 체인[1-6].webp`
- **조작 아이콘**: `riragameinfo/ww images/common/position/key [KeyName].webp` (예: /점프 등 특수 텍스트는 그대로 유지)

### 3.2. 텍스트 강조 규칙
- **자동 하이라이트**: `[속성명] 피해` (예: 인멸 피해) -> 자동 속성 색상 적용
- **제외 사항**: `[속성명] 피해 보너스`는 자동 하이라이트에서 제외 (일반 텍스트 유지)
- **수동 하이라이트**: `==키워드==` (노란색 강조 + 툴팁), `**제목**` (골드 서브타이틀)
