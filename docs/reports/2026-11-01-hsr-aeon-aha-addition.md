## 연결과 표시

- 4.7 캐릭터를 등록 목록 맨 앞에 추가했다. 기존 93명을 교체하지 않았으며 총 94명이다.
- 빌드가 도감·관련 캐릭터 요약, 통합 검색과 이름 별칭, 선택한 상세 JSON, 사이트맵·허용 경로, 검색용 초기 HTML을 생성한다.

- 업데이트 일자는 원문 입력·검수일인 2026-11-01을 사용한다. 4.7의 미확정 출시 날짜를 추가하지 않았다. 날짜가 없는 기존 캐릭터의 처리 방식은 유지한다.

## Git 훅의 내부 위키 생성 범위 보정

캐릭터 원본 commit 시 저장소의 기존 pre-commit 훅이 `rebuild_hsr_wiki.py`를 실행했다. 이 스크립트는 로컬 파일만 읽고 Notion 동기화를 호출하지 않지만, 요청하지 않은 기존 캐릭터 위키 8개까지 재생성·stage했다. 해당 경로에 작업 시작 시 사용자 변경이 없었음을 확인한 뒤 그 8개만 작업 전 commit으로 복원하는 후속 commit을 만들었다. 신규 `10_Wiki/👥 Characters/HSR/aeon-aha.md`만 남겼으며 자동 생성된 과거 날짜·근거 없는 신뢰도 값도 정정했다. 공개 이력을 강제로 재작성하지 않았다. 문서 범위 후속 변경이므로 본문·diff 검증으로 확인하며, 캐릭터 코드·생성 데이터는 앞선 타입·전체 build·596개 테스트 통과 상태와 동일하다.
