# 독립 검토: 디자인·UX 평가 절차

- 담당: design_protocol 에이전트.
- 대상 baseline: c24f68d, DESIGN.md·상태 체크리스트·공통 Layout 및 대표 페이지 로컬 검토.
- 파일 수정·production 전체 화면/상호작용 검사: 미실행.

## 독립 판단

새 문서는 디자인 정책을 복제하지 않고 DESIGN.md의 실행·증거 절차로 연결해야 한다. 같은 화면 크기·언어·동의 상태에서 첫 화면·중간·푸터·모달을 캡처하고 실제 키보드/터치 여정을 수행해야 한다.

390×844·768×1024·1440×900, 좁은 320px·200% 확대, 긴 이름·번역, Loading/Empty/Error, 이미지와 실제 원본을 비교한다. 모바일 에뮬레이션과 실제 기기는 구분한다.

## 현재 한계와 주의

- Layout의 overflow-x-hidden 때문에 scrollWidth만으로 잘림 여부를 확정하면 안 된다.
- tests/e2e의 소스 검사는 실제 콘솔·화면·WCAG 전체 검증이 아니다.
- FeedbackReportModal의 성공 UI는 소스상 데모 동작일 수 있으므로 실제 서버 접수 여부를 별도로 검증해야 한다. 이 문서 작업에서 해당 기능은 바꾸지 않았다.

판정: 절차 제안 완료. 전체 시각·접근성 합격 판정은 하지 않음.

## 초안 교차 검토

DESIGN.md 비복제와 안전한 증거 보관을 확인했다. 존재하지 않는 `/guides` 표본과 기존 테스트를 실제 대비 계산으로 오해하게 하는 문구를 지적했고 주 담당이 모두 수정했다. 운영 권한 변경 없이 인증·오류·관리자 UI를 확인하는 절차는 적절하다.
