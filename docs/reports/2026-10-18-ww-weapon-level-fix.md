# WW 무기 레벨 슬라이더 수정

일자: 2026-10-18 KST. 기준 commit: `627f806` 이후 변경.

## 원인 및 변경

모든 무기에 고정 레벨 배열 `[1,20,40,50,60,70,80,90]` 및 90레벨 기준 비율을 사용했다. 기존 DB의 1·2성 무기는 마지막 성장 행이 70레벨이므로, 끝점이 90으로 잘못 표시되고 중간 수치도 90레벨 비율로 계산됐다.

- `ww-hub/utils/weaponLevels.ts`: 1·2성의 기존 growthStats를 파싱해 실제 레벨·공격력·부옵션을 반환한다. 3~5성은 기존 계산 경로 유지.
- `ww-hub/pages/WuwaWeaponDetail.tsx`: 슬라이더 최대 인덱스·라벨·선택 값·수치를 같은 레벨 목록에 연결. 초기 인덱스가 범위를 벗어나면 상한으로 제한. 접근 가능한 이름 및 실제 레벨 aria-valuetext 추가.
- `tests/ww-weapon-levels.test.ts`: 태초의 권갑 6개 성장 행 대조, 저성급 10개 끝점·원본 불변성, 고성급 기존 경로 및 비정상 데이터 fallback 검사.
- `tests/ww-weapon-level-slider.test.tsx`: 실제 React 화면에서 최대 Lv.70, Lv.1·50 변경 및 표시 수치 검사.
- 원본 DB·Notion·스킬·이미지·여백·카드 크기는 수정하지 않았다.

## 의미상 검증

기준은 현재 로컬 생성 JSON과 그 안의 기존 성장 표다. 신규 Notion 동기화 또는 외부 게임 데이터의 전수 정확성 검증은 아니다.

- 1성 5개·2성 5개 모두 70레벨 끝점이 현재 stats와 일치함을 검사했다.
- 태초의 권갑: Lv.1 공격력 22/공격력 3.3%, Lv.50 142/9.7%, Lv.70 209/12.3%.
- 실제 로컬 production 브라우저에서 최대 70과 본문 확인. 키보드 Home/End로 Lv.1과 Lv.70을 직접 조작해 위 수치와 대조했다. 데스크톱 화면을 직접 확인했다.
- 모바일 전수·전체 접근성·고성급 모든 성장 수치 검증은 미수행이다.

## 경계와 남은 점

해석할 수 없거나 중복된 원본은 기존 모델로 fallback한다. 현재 저성급 10개는 모두 파싱되지만, 향후 데이터 형식이 바뀌면 회귀 테스트와 의미 검증이 필요하다. 3~5성의 기존 보간 수치와 별도 커스텀 표는 이번 작업에서 재작성하지 않았다.

Git push·CI·Cloudflare 및 운영 반영 여부는 완료 응답에서 실제 확인 결과로 구분해 보고한다. 기존 보류 AGENTS.md 및 이전 보고서는 이번 커밋에서 제외한다.
