# HSR 공략 접근 및 공개 데이터 수정

2026-10-30 KST. 기준 HEAD: `040f9cc3e8e19c7ce30f64df27e07f018a856f71`.

## 결과

- 운영에서 블랙 스완·토오사카 린·더 헤르타 공략의 HTTP 404와 noindex를 직접 재현했다. 로컬 브라우저에서 내용이 보이는 것만으로 운영 경로 정상이라고 판단하지 않는다.
- 등록 import의 파일명과 캐릭터 표시명을 직접 비교하던 로직이 공백·특수 표기 차이를 처리하지 못했다. 등록 파일 안의 명시적인 characterName을 공백/NFC 정규화로 연결한다. 임의 ID 추정이나 미등록 페이지 허용은 하지 않는다.
- 생성 라우트의 HSR 캐릭터 공략이 73개에서 93개로 증가했다. 알려진 3개를 포함해 동일 원인의 누락 20개를 복구했다. lastmod는 ID로 추정한 경로 대신 실제 등록 파일에서 읽는다. 등록 충돌·파싱 오류는 빌드 실패로 처리한다.
- 계산 조건이 확인되지 않은 eidolonEfficiency/eidolonVariants 비교표를 HSR 공개 변환 단계에서 비운다. 로컬 원본 TS, 추천 성혼, 장비 추천, 분석과 변형 세팅을 보존했다.
- 초기 HTML, 개별 runtime JSON, 목록·장비 추천용 공개 카탈로그와 React 경계에 같은 정책을 적용했다. 클라이언트의 원본 가이드 import를 공개 카탈로그로 바꿔 JS 잔존 경로도 제거했다.
- 새 manifest가 참조하지 않는 정해진 형식의 생성 JSON만 고정 출력 폴더에서 정리한다. 과거 배포와 사용자 브라우저에 이미 저장된 캐시까지 철회했다는 뜻은 아니다.
