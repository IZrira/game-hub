# UI 편의성 개선 1차

일자: 2026-10-18 KST. 기준: main `96f05f5` 이후 변경.

## 변경

- `common-hub/pages/Home.tsx`: 히어로 상하 간격·제목 크기·검색 위 간격을 압축했다. 외곽 수평 여백과 게임 카드 크기·링크·검색 기능은 유지했다. 한글 단어 단위 줄바꿈을 적용했다.
- `ww-hub/pages/PartyRecommendations.tsx`: 400px 고정 소개를 콘텐츠 높이로 바꾸고 ‘명조 추천 파티 조합’ 제목을 적용했다. 기존 편성 안내는 삭제하지 않고 native details로 접는다. 카드·파티 데이터·검색 로직은 유지했다.
- `aniimo-hub/pages/Gallery.tsx`: 검색·필터를 지역 탐색 앞에 배치하고 소개를 압축했다. 검색 입력에 접근 가능한 이름을 추가했다. 지역·4개 필터·비교·전체 목록 데이터는 유지했다.
- `tests/aniimo-gallery-empty.test.tsx`, `tests/ww-party-intro.test.tsx`: 검색 순서·필터 보존·한국어 제목·접기 안내 원문·기존 파티 검색 검증.

## 실제 화면 검증

새 production 빌드를 로컬 브라우저에서 한국어·로그아웃으로 확인했다. 점검 후 viewport를 복원했다.

- 390×844 홈: 첫 게임 카드 y=743 → **591px**, 152px 위로 이동. 카드 약 350×178px 유지.
- 1440×900 홈: 게임 카드 y=846 → **708px**, 138px 위로 이동. 약 267×178px 카드 4개가 첫 화면 안에 들어온다.
- 320×844 홈: 한글 제목이 단어 단위로 줄바꿈하고 body width/scrollWidth가 312px로 동일했다. 핵심 콘텐츠 가로 잘림을 관찰하지 않았다.
- 390×844 애니모: 이름 검색 y=972 → **580px**, 392px 위로 이동. 입력 높이 48px 유지. 결과 없음 검색과 ‘검색 조건 초기화’ 복구를 실제 조작했다.
- 390×844 WW 파티: 검색 약 y=630px, 첫 파티 제목 약 y=810px. 이전처럼 첫 화면이 대형 영어 소개와 안내만으로 채워지지 않는다. native 안내 클릭 펼침과 Enter 접기를 확인했다.
- 세 화면의 1440px 데스크톱 및 390px 모바일 렌더링을 직접 열어 검토했다. 320px 검사는 홈만 추가 수행했다. 모든 화면·모든 다국어·200% 확대를 전수 검사한 것은 아니다.

수치는 이전 운영 UI 점검 보고서와 같은 viewport의 새 로컬 production 화면을 비교한 값이다. 서버 속도·LCP 개선율이 아닌 화면 배치 변화다. 로컬 공지 등 운영 API 상태 차이는 배치 변경과 구분한다.
