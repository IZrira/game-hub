# NTE 이동수단 원문 대조·추가 성능 반영

사용자 지시: 지정한 [이환/차량 문서](https://namu.wiki/w/%EC%9D%B4%ED%99%98/%EC%B0%A8%EB%9F%89)를 기준으로 기존 오류를 수정하고 누락 목록과 펼쳐진 상세 성능을 웹사이트에 반영한다. 사용자 첨부 사진의 「미래로 질주!」 기본 제원도 함께 대조했다.

## 반영 순서와 범위

1. 기존 제원·획득처·출시 예정 표기 정정.
2. 미등록 주요 목록 9종과 구매 불가 목록 11종 추가.
3. 문서의 상세 성능 접기 제어 32개를 실제 클릭해 펼친 뒤 5개 추가 항목을 반영.

최종 43종 = 기존 23종 + 주요 목록 9종 + 구매 불가 11종. 추가 성능은 원문에 값이 있는 32종·160개 필드만 제공한다. 구매 불가 11종의 기본·상세 제원은 추정하지 않았다.

## 주요 정정

- LaVelox 최고속도 191→197, B100 내구도 17,000→14,600.
- K01 최고속도 140→80, 가속 9→8, 내구도 7,200. 최고속도는 부스트 미사용 기준임을 설명에 명시. 문서 본문의 ‘무한 내구도’ 설명을 수치표와 섞지 않았다.
- 「미래로 질주!」 내구도 5,400, 「옛 시절」 4,400, 「열풍」 9,150.
- Tide 최고속도 108·가속 5, 한국어 획득 박스명 반영.
- 타이칸 내구도 20,500, 911 내구도 16,750. 두 항목의 ‘출시 예정/획득 방법 미공개’를 문서의 ‘폭주의 그림자’ 박스 정보로 변경. 타이칸 정식 패키지명 포함.
- K01 현금 가격 32,000원, B100 발바닥 코인 표기, 자전거 매장과 란드릭 제조사 구분, 918 Spyder·Draco 박스명 반영.
- 「옛 시절」의 페달링 최대 70km/h, Tide의 점프·조선소 튜닝 설명 보강.

## 추가 목록

주요 목록: A001, E001, C001, 철강호, Ori-TT01, Ori-LV01, Ori-LV03, 육지의 지배자 001 시제품, 「미래로 저어라!」.

구매 불가 목록: 경형트럭, 푸드트럭, 대형트럭, 지게차, 로더, 롤러, 굴착기, 시내버스, 택시, 경찰차, 소형 선박.

구매 불가 항목은 지상·수상 별도 분류와 카드 배지로 구별한다. ‘육지의 지배자’는 원문의 1.6 버전 표기를 유지했다. 원문에 없는 버전은 새로 붙이지 않았다.

제조사에 란드릭·오리컬코스·Porsche를 추가했다. 고정 제조사 목록에 없다는 이유로 카드가 누락되지 않도록 그룹 처리를 변경했다. 바퀴 수와 ATV·전차 등을 혼동하지 않도록 기존 ‘2륜/4륜’ 분류명을 문서의 이동수단 범위에 맞게 바꾸고, 기존 분류 URL은 별칭으로 처리했다.

## 추가 사양의 의미 보존

변속 시간, 서스펜션 높이, 서스펜션 댐핑, 핸드 브레이크, 제동력을 차량별 접기 영역에 표시한다. 화면에서 직접 확인한 특성 방향은 각각 느림↔빠름, 낮음↔높음, 부드러움↔딱딱함, 약함↔강함이다. HTML 자식 순서만 읽으면 실제 좌우 배치와 반대라 렌더 화면과 대조했다.

「미래로 질주!」의 추가값은 0·1·9·7·5. 숫자 0을 미공개로 처리하지 않는다. A001·C001·철강호·Ori-TT01에는 30·40·60 등 다른 범위의 값이 함께 기재돼 있다. 사용자 지정 원문을 기준으로 그대로 보존했고 임의로 10으로 나누거나 0~10 그래프로 정규화하지 않았다. 단위가 없는 값을 초·%로 바꾸지 않았다.

## 이미지

추가 20종에 실제 차량 이미지 20개를 `public/assets/nte/vehicles`에 저장했다. 전부 WebP 디코딩·크기·응답을 확인했으며 서로 다른 SHA-256 20개, 합계 1,219,066바이트다. 차량 이미지와 통화 아이콘을 구별했고, 연락시트로 차명·외형을 직접 대조했다. 새로운 AI 이미지나 공통 대체 이미지는 만들지 않았다.

기존 「미래로 질주!」 이미지는 초기 캡처에서 늦게 표시됐지만 실제 URL HTTP 200·정상 WebP였다. 이미지 디코딩까지 기다린 화면에서 정상 표시를 확인해 불필요한 경로 변경은 하지 않았다.

## 구현 파일

- `nte-hub/data/vehicles.ts`: 목록·제원·추가 성능·분류·제조사·획득 정보 원본.
- `nte-hub/pages/Gallery.tsx`: 전체 그룹 표시, 구매 불가·버전 표시, 기존 필터 별칭, 상세 성능 연결.
- `nte-hub/components/VehiclePerformance.tsx`: 네이티브 details/summary와 5개 사양. 키보드 조작·포커스 표시 유지.
- `public/assets/nte/vehicles/*.webp`: 이번 추가 20개 파일만 포함.
- `tests/fixtures/nte-vehicle-reference.json`: 확보한 문서의 43종 기본 제원·추가 성능 참조. 원문 설명은 복제하지 않음.
- `tests/nte-vehicles.test.tsx`: 모든 원문 값, 카드 그룹 누락, 미공개·0 구분, 이미지 헤더, 출시 상태·통화와 상세 UI 회귀 검사.

공개 페이지에 출처 사이트명·출처 링크·Notion 링크를 추가하지 않았다. 기존 레이아웃·검색·정렬·이미지 경로를 유지하되 설명·획득 문구는 읽는 본문 규격 16px로 표시한다. 이 원본은 Notion 동기화 대상이 아니다.

## 검증

- 타입 검사 통과.
- Notion lifecycle 동기화 없이 production build 통과.
- 빌드 SEO 감사·성능 예산 통과. 기존 짧은 공지 설명 경고는 유지.
- 전체 106파일·808개 테스트 통과.
- 디자인 기계 검사 결과 추가 경고 없음.
- 로컬 1280px·390px에서 각각 카드 43개, 기본 값 129개, 추가 값 160개 일치. 키보드로 펼치기와 닫기, 새 제조사 Ori-LV03 검색, 기존 4륜 필터 URL 이동 확인. 가로 넘침·pageerror 없음.
- 대표 모바일·데스크톱 화면과 신규 이미지 연락시트를 직접 열어 확인.
- 변경 파일 diff·신규 파일·스테이징 범위를 확인한 뒤 이번 작업만 commit·push한다. CI·운영 배포·배포 후 검증은 완료 응답에 실제 결과를 보고한다.

성능은 빌드 예산과 lazy 이미지 유지, 보안은 내부 에셋·텍스트 렌더·운영 권한 무변경, UX는 위 브라우저 표본으로 범위를 나누어 확인했다. 별도 3인 독립 평가나 전체 보안·접근성·성능 감사는 수행하지 않았다.
