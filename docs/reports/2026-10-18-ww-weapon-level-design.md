## 결론

정적 범위에서 차단 결함을 발견하지 않았다. 기존 레이아웃을 유지하면서 실제 원본의 최대 레벨·수치를 표시하는 변경이다. 실제 화면과 전체 접근성 통과 판정은 하지 않는다.

### D1 — 1·2성 원본 수치 보존: PASS, 로컬 대조

현재 로컬 원본은 1성 5개, 2성 5개다. 모두 마지막 성장 행이 70레벨이며 1성은 공격력 190·부옵션 9.5%, 2성은 공격력 209·부옵션 12.3%로 기본 stats와 일치한다. 새 함수는 성장 행에 기록된 수치를 읽어 직접 표시하고 원본 데이터를 변경하지 않는다. 태초의 권갑 테스트의 1/20/40/50/60/70레벨 값은 원본에 대응한다. 모든 저성급 끝점과 원본 불변성 검사가 추가되어 있다. 외부 게임 자료·Notion을 새로 조회한 검증은 아니다.

### D2 — 3~5성 경로 유지: PASS, 정적 검사

3성 이상은 기존 `[1,20,40,50,60,70,80,90]`와 rows=null을 반환해 기존 계산 함수를 사용한다. 기존 성장 보정 함수·게임 데이터는 변경하지 않는다. 이를 확인하는 세 성급 테스트가 있다.

### D3 — 인덱스·조작 의미: PASS, 현재 UI 입력 경로 한정

기존 초기 인덱스 7을 현재 최대 인덱스로 상한 제한한다. 저성급은 기본적으로 인덱스 5, Lv.70으로 표시되어 존재하지 않는 Lv.90이나 undefined 수치가 노출되지 않는다. range의 max·value·말풍선 위치·끝점 라벨 모두 동일한 레벨 배열을 사용한다. 정상 UI 입력은 range의 min=0과 max로 제한되므로 현재 경로에서 음수 인덱스 유입 근거는 없다. 반환 배열은 최소 2행 또는 기존 8행이므로 말풍선 위치 계산의 0 나눗셈도 없다.

### D4 — 크기·여백·접근 가능한 이름: PASS, 정적 한정

기존 카드·외곽 여백·슬라이더 스타일 className은 유지한다. range에 번역 가능한 `무기 레벨` 이름과 실제 레벨을 설명하는 `aria-valuetext`가 추가된다. 내부 값이 레벨 자체가 아니라 배열 인덱스인 UI에서 보조 기술에 실제 Lv.값을 제공하는 개선이다. 테스트는 slider의 이름, 최대 인덱스, Lv.70 시작, Lv.1·50 변경과 대응 수치 표시를 확인하도록 구성되어 있다. 이 에이전트가 테스트를 직접 실행한 것은 아니다.

### D5 — 실제 화면·키보드·접근성: UNVERIFIED

390×844·1440×900 화면, 말풍선 끝점 잘림, 키보드 방향키·Home·End, 다국어 접근 이름, 고성급↔저성급 SPA 전환은 브라우저에서 직접 확인하지 않았다. 주담당의 실제 화면 검증으로 보완해야 한다. WCAG 전체 적합성·대비·콘솔 정상 여부는 판정하지 않는다.

## 경계와 후속 검토

해석 불가능한 저성급 성장 데이터는 기존 레벨 모델로 fallback한다. 현재 10개 원본에는 끝점이 존재하지만, 향후 원본 형식 변경이나 일부 행 누락이 생기면 fallback·부분 해석의 의미 검증이 필요하다. 이 가능성은 현재 데이터의 확정 결함으로 분류하지 않는다.

디자인 → 보안 관점에서 인증·관리자·오류 상태·권한 UI 변경은 없다. 원본 수치를 읽어 텍스트로 표시하며 새로운 외부 링크·실행 동작은 추가하지 않는다. 보안 담당의 독립 검토를 대신하지 않는다.

## 실행 제한
