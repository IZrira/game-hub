## 1. 주요 구현 내용
### 딥링크(Deep Linking) 기능 강화
*   **HSR/WW 공통**: 캐릭터 상세 페이지의 '상세 공략'/'공략 바로가기' 버튼 클릭 시, 메인 허브의 공략 탭으로 이동하며 해당 캐릭터가 자동으로 검색되도록 로직을 수정했습니다.
    *   경로: `/gallery/${gameId}?menu=공략&search=${char.name}`

### WW 갤러리 공략 탭 추가
*   **UI 이식**: `hsr-hub`의 공략 탭 디자인과 필터 로직을 `ww-hub/pages/Gallery.tsx`에 이식했습니다.
*   **데이터 연동**: `dataManager.ts`를 수정하여 `ww-hub`에서도 공략(GUIDES) 데이터 구조를 인식하고 반환할 수 있도록 아키텍처를 보강했습니다.
*   **준비 중 상태 처리**: 현재 `ww-hub`에 실제 공략 데이터가 없는 점을 고려하여, 공백 상태 대신 세련된 "준비 중" 플레이스홀더를 표시하도록 구현했습니다.

## 3. 테스트 및 검증 결과
*   **런타임 에러 해결**: `useGalleryFilter.ts`에서 `name` 필드가 누락된 아이템 검색 시 발생하던 `toLowerCase()` 에러를 방어 코드로 해결했습니다.
*   **HSR**: 상세 페이지에서 버튼 클릭 시 공략 탭이 열리고 해당 캐릭터 카드만 정확히 필터링됨을 확인했습니다.
*   **WW**: 상세 페이지에서 버튼 클릭 시 공략 탭으로 이동하며 "준비 중" 메시지가 정상 노출되는 것을 확인했습니다.
*   **라우팅**: 모든 딥링크 파라미터(`menu`, `search`)가 브라우저 히스토리 및 탭 상태와 완벽히 동기화됩니다.

이제 사용자는 캐릭터 상세 정보를 보다가 즉시 관련 공략 리스트로 넘어가서 원하는 정보를 더욱 빠르게 찾을 수 있습니다.

## [2026-04-29] 티어표 관리 시스템 고도화 및 캐릭터 에셋 매칭 정규화
 
### 주요 구현 내용
*   **어드민 대시보드(Admin Dashboard) 기능 개선**:
    *   **미편성 캐릭터 우선 노출**: 티어표 관리 탭에서 티어 미지정 캐릭터(`?`) 섹션을 최상단으로 이동하여 신규 캐릭터 배정 편의성을 극대화했습니다.
    *   **도감 데이터 동기화 기능**: `characters.json` 파일의 최신 캐릭터 정보를 클릭 한 번으로 DB(`characters` 테이블)에 업서트(Upsert)하는 전용 버튼을 추가했습니다.
    *   **매칭 로직 강화**: 이름 정규화(`normalizeName`) 함수에 유니코드 NFC 처리 및 특수 문자 필터링을 보강하여 도감과 티어표 간의 데이터 연결 안정성을 확보했습니다.
    *   **우선순위(Priority) 저장 버그 수정**: 관리자 페이지에서 캐릭터 우선순위를 `0`으로 설정할 때 `100`으로 자동 복구되던 현상을 해결했습니다.
*   **캐릭터 에셋 및 데이터 정규화**:
    *   **더 헤르타(5성) 이미지 복구**: `folderName` 매칭 오류(헤르타 -> 더 헤르타)를 전수 수정하여 5성 전용 일러스트가 정상 출력되도록 조치했습니다.
    *   **개척자 시리즈 이미지 로드 오류 해결**: `characters.json` 내 `folderName`의 괄호 앞 공백 누락(`개척자(기억)` -> `개척자 (기억)`) 문제를 일괄 수정하여 이미지 경로를 GitHub 저장소 구조와 일치시켰습니다.
    *   **신규 캐릭터 추가**: **에바네시아** 및 **개척자 (환락)**를 도감(`characters.json`) 및 티어표(`tiers.ts`) 데이터에 정식 등록했습니다.

    *   제공받은 최신 HSR 티어표 데이터를 전체 반영하고, 관리 도구를 통해 로컬 데이터와 DB 간의 완벽한 정렬을 완료했습니다.
