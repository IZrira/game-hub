# SEO 개선 2차 — WW 무기 초기 HTML 일관성

일자: 2026-10-18, 한국 시간. 기준: main `f15d5f5` 이후 변경.

## 진단과 수정

- 이전 Search Console 보고서에서 Soft 404로 관찰된 `전우의 의리`, `태초의 권갑`의 현재 운영 초기 HTML 및 실제 상세 화면을 비교했다. 두 경로 모두 200이며 실제 본문이 표시됐다. 이번에는 Search Console을 재조회하지 않았으므로 과거 판정의 해제 여부는 미확인이다.
- 초기 제목은 ‘옵션 비교 및 추천 착용 캐릭터’, description은 ‘완벽 분석 가이드’였지만 실제 화면은 무기 DB였다. 추천 캐릭터가 없어도 같은 약속을 하던 초기 메타를 실제 화면의 제목·설명에 맞췄다.
- `common-hub/utils/wwWeaponSeo.js`를 추가해 React와 초기 HTML 생성기가 같은 제목·설명 원본을 사용한다. 초기 H1도 실제 화면의 무기명과 일치시켰다.
- 성장 데이터가 70레벨까지인 태초의 권갑에도 초기 HTML에 일괄 붙던 ‘1~90Lv’를 제거했다. 원본 수치·성급·스킬·추천 목록·획득처·기존 레이아웃은 변경하지 않았다.
- 같은 생성기를 사용하는 다른 WW 무기도 정직한 DB 메타 형식을 적용받는다. 분류 원본이 없으면 성급·무기 유형을 임의로 만들지 않는다.

## 남은 항목

- 이 변경이 Google Soft 404의 유일한 원인을 해결했다고 단정하지 않는다. Google 저장 렌더링·선택 canonical 및 재크롤링 결과 확인이 필요하다. 색인 요청·사이트맵 재제출·유효성 재검사는 실행하지 않았다.
- 태초의 권갑 원본 성장 데이터는 70레벨까지인데 실제 화면 스탯 슬라이더는 Lv.90을 표시한다. 초기 HTML의 잘못된 범위만 제거했으며, 런타임 레벨 선택·계산은 이번 SEO 변경에 포함하지 않았다. 후속으로 저성급 무기의 최대 레벨과 성장 표·계산기를 함께 대조해야 한다.
- 전우의 의리 성급은 기존 로컬 DB 값을 그대로 사용한다. 게임 원자료 대조 없는 임의 수정은 하지 않았다.
- commit·push·CI·Cloudflare 및 운영 최종 반영 결과는 작업 완료 응답에서 해당 실행 결과로 구분해 보고한다.
