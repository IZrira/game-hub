## 판정

변경 범위의 정적 검토에서 P0/P1 성능 회귀는 발견하지 않았다. 다만 이미지 전송량과 실제 로딩 지표는 미측정이므로 실사용 성능 통과를 선언하지 않는다.

### PASS — 공통 소개 컴포넌트의 의존 범위

HubIntro는 React 상태, 기존 router, 기존 아이콘만 사용한다. 검색 입력 상태는 소개 컴포넌트 내부에 있어 매 입력마다 상위 Gallery 전체 상태를 직접 변경하지 않는다. 별도 네트워크 요청·타이머·전역 이벤트를 추가하지 않는다.

### PASS — 가이드 본문 재유입 없음

ReviewedGuideHighlights는 기존 guideSummaries의 메타데이터를 사용한다. NTE 홈에 새로 연결되었지만 전체 guideArticles 본문을 런타임 정적 import하지 않는다. 카드/목록 variant는 같은 최대 3개 항목을 사용한다.

### PASS — 기존 데이터·카드 보존

HSR·WW·NTE 최근 캐릭터 목록의 원본과 최대 5개 제한은 유지되어 있다. 카드 자체의 이미지 로딩 정책을 이 변경에서 새로 복제하지 않는다. Aniimo는 이미 사용하던 summary JSON을 재사용하고 진화 관계를 새로 계산하거나 전체 상세 DB를 추가 import하지 않는다.

## 비차단 후속 점검

### PERF-01 — Aniimo 홈 이미지 요청 증가 후보 / P2 / UNVERIFIED

- 신규 찾아보기는 원본 PNG 4개를 표시하며 상위 2개는 eager, 나머지는 lazy다. 기존 대표 이미지 1개와 달리 작은 카드가 여러 요청을 만들 수 있다.
- LazyImage의 async decoding·고정 정사각형 영역·실패 fallback은 유지한다. 이 사용처에는 srcset/sizes가 없다.
- 실제 원본 바이트와 브라우저 요청 시점은 측정하지 않아 느려졌다고 확정하지 않는다.
- 다음 점검: 390×844·1440×900 콜드 진입에서 카드 표시 크기, 이미지 전송량과 요청 수를 확인한다. 크기가 과도하면 원본을 훼손하지 않는 기존 썸네일 파이프라인 적용을 별도 검토한다. 첫 카드 4개를 모두 high priority로 바꾸지 않는다.

### PERF-02 — 접힌 분포는 JS 지연 로딩이 아님 / P3 / 관찰

- HSR·WW의 native details 안에도 GlowStatsDistribution이 React 자식으로 마운트된다. 해당 컴포넌트는 useMemo 집계와 framer-motion 의존을 그대로 갖는다.
- 기존 분포가 삭제되지 않은 점은 적절하다. 접기로 시각적 정보량은 줄지만 초기 JS·집계 비용이 없어졌다는 표현은 부정확하다.
- 현재 데이터 규모에서 긴 작업이 발생하는지는 미측정이며 이 변경으로 비용이 증가한 증거는 없다. 실제 병목이 확인될 때만 별도 지연 마운트를 검토한다.

## 미검증 및 인계

- 타입·테스트·build·gzip 예산·SEO 검증은 주 담당의 최종 변경본 실행 결과를 사용해야 한다. 본 담당은 이를 별도 실행하지 않았다.
- 브라우저 전후 비교, 네트워크/CPU 제한, 콜드·웜 각 3회 측정, FCP/LCP/CLS/TBT/INP 및 현장 CWV는 미검증이다.
- 성능 향상 비율이나 임의 점수를 부여하지 않았다. 신규 레이아웃의 의미는 정보 접근성 개선이며 페이지 가속을 확정하는 증거는 아니다.
- 성능→디자인 교차 검토용 관찰: 기존 데이터 분포는 펼침으로 남아 있고, 최근 캐릭터·가이드·카테고리는 유지된다. 원본 데이터나 광고를 제거해 수치만 개선한 diff는 확인하지 못했다.

## 독립 결론 고정 후 교차 검토

- 디자인 담당 보고서를 독립 결론 작성 후 읽었다. 카테고리·요약 통계·최근 캐릭터·가이드·분포가 보존되었다는 소스 판단에 동의한다. compact UI를 위해 실제 원본 데이터를 삭제한 정황은 없다.
- Aniimo 첫 4개 이미지는 기존 summary의 imageUrl을 참조한다. 가짜 진화 계보나 생성 이미지를 데이터로 넣지 않고 실제 상세·가이드로 연결한다는 디자인 판단도 소스와 일치한다.
- 주 담당이 TypeScript, build의 890개 SEO 경로 및 성능 예산, 62개 파일의 421개 테스트 통과를 전달했다. 이는 주 담당 실행 결과이며 본 담당의 별도 실행·실측 결과는 아니다.
- 디자인 D1 제목 계층 차이는 데이터·성능을 훼손하지 않는 범위에서 정리할 수 있다. D2 하단 메뉴 길이는 브라우저 관찰 후 판단하는 것이 적절하며 성능 점수를 위한 삭제 근거가 아니다.
- PERF-01 이미지 전송량·CWV는 여전히 UNVERIFIED다. 보고서 사이에 차단급 이견은 없다.
