# NTE 비틀 코인 3성 반영

- Notion 아이템 DB의 비틀 코인 원본은 3성이다. 기존 로컬 기본값이 1성이어서 회색 재료 아이콘으로 표시됐다.
- 공식 동기화 스크립트에 NTE 아이템 전용 범위를 추가하고 실행했다. Notion 아이템 1,230 → 1,231개. 캐릭터·아크 DB와 Notion 원본은 수정하지 않았다.
- 공통 생성 아이템 정보와 로컬 기본값 모두 3성으로 맞췄다. 기존 이미지와 레이아웃은 유지한다.
- 캐릭터 24명과 아크 51개의 실제 육성 재료 수량으로 공통 아이콘 렌더링을 검사한다. 3성 파란 테마와 회색 테마 비적용을 검증한다.
- 동기화는 인증 누락·조회 오류·빈 결과에서 덮어쓰지 않도록 방어한다. 다른 DB와 기존 레코드 순서는 보존한다.
- TypeScript 및 build 통과. SEO·성능 예산 검사 통과. 관련 회귀 테스트 83개 통과 후 최종 변경도 재검사한다.
- AGENTS.md와 기존 미커밋 보고서는 작업 범위에서 제외한다. 운영 화면 확인 및 배포 상태는 최종 보고에서 구분한다.
