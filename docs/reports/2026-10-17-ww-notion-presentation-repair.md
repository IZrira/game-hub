# WW 동기화 데이터 파싱·표시 전수 수정

## 원인과 범위

갈브레나 스크린샷에는 내부 번역 키 노출과 조작 입력 중복이 있었다. 앞선 두 캐릭터 원본 재동기화와 플로로 입력 접미사 수정은 이 공통 파싱 결함을 해결하지 못했다.

기존 dataManager는 빈 줄 사이의 맨문자 조작 입력/메커니즘 설명만 구분했다. Markdown 강조 제목이나 소제목을 놓치면 입력 문장이 개요에 남고 기존 로컬 입력 키가 다시 붙었다. WW 60명을 재귀 검사해 한국어 리소스가 없는 내부 키 29개/9명을 확인했다. 독립 검토에서 제목 형식 문제 영향 후보는 19명이었다.

## 수정

- 공통 파서가 plain/bold/Markdown heading/소제목/CRLF/문서 첫 줄의 독립 제목을 처리한다. 문장 중간의 같은 단어는 분리하지 않는다.
- 원문의 입력 순서·수치·강조·아이콘 표기는 유지하고 반복 소제목만 제거한다. 기존 combatCycle 우선권과 비어 있는 원문에 대한 로컬 fallback 흐름은 유지한다.
- 누락된 고유 스킬·조화도 파괴 번역 참조만 같은 캐릭터 Notion 스킬 원문으로 복원한다. 배열 위치가 아니라 notion_inherentSkill1/2, notion_harmonyBreak 식별자로 매칭한다. 등록된 번역·리터럴·아이콘은 유지한다.
- 빌드가 해결되지 않은 WW 내부 번역 키를 발견하면 실패하도록 보호한다. 단순히 내용을 숨겨 오류를 감추지 않는다.

## 데이터 대조

원격 Notion 재동기화 없이 최신 저장 원본으로 다시 생성했다. Notion JSON·로컬 캐릭터 원본·locale·디자인 컴포넌트는 변경하지 않았다. 60명/정렬 유지. 스탯·명칭·이미지·무기·재료 변경 없음. 생성 변경은 27명의 skillInput/additionalAbilities/concertDissipation 필드에 한정됐다. 한국어 번역 누락 키 29개에서 0개로 감소했다.

갈브레나는 게이지+개요와 강공격/공중 공격/지옥 관통 입력 3개가 분리되고 중복이 제거됐다. 전체 저장 원본에서 제목만 제외한 텍스트와 분리 결과 합산 텍스트의 정규화 대조를 테스트한다. 의미 검증은 단순 타입 검사와 구분한다.

## 검증·검토

타입 검사와 54파일 385테스트 통과. 회귀 검사는 제목 변형·문장 비분리·원문 전수 보존·미번역 참조 전수 검사·고유 스킬 중간 누락 방어·갈브레나 실제 컴포넌트의 키 노출/중복 없음 등을 포함한다. 최종 build/성능 예산/diff/CI/배포와 브라우저 결과는 완료 보고에 명시한다.

최종 production build·SEO·성능 예산·diff 검사도 통과했다. 로컬 production 미리보기 브라우저에서 갈브레나의 게이지/개요와 입력 3개의 시각 배치·키/마우스 아이콘을 직접 확인했다. DOM에서도 내부 입력 키 미노출과 조작 입력 제목 1개를 확인했고, 루파 추가 표본에서도 내부 입력 키 미노출/제목 1개를 확인했다. 운영 모든 캐릭터의 브라우저 전수 방문이나 전 언어 시각 검증을 수행한 것으로 확대하지 않는다.

성능·보안·UX 에이전트가 독립적으로 원인과 diff를 검토했다. 보안 검토의 고유 스킬 정체성 우려는 식별자 매칭과 회귀 테스트로 보완했다. 권한·CSP·인증·외부 HTML 렌더링을 바꾸지 않았다. 성능 실측 향상을 주장하지 않는다. 영어·일본어 전체 번역의 완성도 감사는 이번 한국어 누락키 수정 범위와 구분한다.
