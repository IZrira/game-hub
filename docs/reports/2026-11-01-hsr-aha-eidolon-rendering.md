# 아하 성혼 표시·렌더링 개선

2026-11-01 KST. 기준 main 8f8b4cd, 범위 HSR 아하 성혼 2 및 공통 성혼 제목.

## 변경과 근거

- 기존 성혼 2는 8명의 효과를 한 번에 용어 강조 처리했다. 회귀 테스트를 먼저 실행해 닫힌 효과도 처리되는 실패를 확인했다.
- 아하 성혼 2만 캐릭터별 독립 토글로 표시한다. 닫힌 효과는 강조 처리와 본문 DOM 생성을 생략하고, 펼치면 원본 전체를 표시한다. 미인식 번역 형식은 전체 원문 표시로 복귀한다.
- 성혼 제목의 말줄임을 제거했다. 기존 열 너비에 맞춰 글꼴을 조절하며 모바일 제목 영역 내부 좌우 여백만 줄인다. 카드 바깥 여백·간격은 유지한다.
- 원본 데이터·효과 수치·초기 HTML 생성 경로는 변경하지 않았다. Notion 동기화 미실행.

## 검증

- TypeScript 및 최종 production build 통과. 빌드의 SEO·성능 예산 감사 통과.
- 전체 회귀 테스트 77개 파일, 598개 테스트 통과. 제한 샌드박스의 임시 파일 ENOENT 실패 후 정상 실행 권한으로 재확인했다.
- 추가 테스트: 닫힘/열림/닫힘 시 본문 처리, 다른 효과 비노출, 8명 전부 원문 일치.
- 인앱 브라우저, 한국어, 로그아웃, 동일 PC 환경. 운영 기준과 로컬 production preview를 비교했다. E2 카드 하위 요소는 닫힘 기준 75개에서 54개로 변경됐다. 이는 DOM 개수이며 FPS 개선율이 아니다.
- 1440×900, 390×844, 320×844에서 6개 제목 모두 scrollWidth ≤ clientWidth, 페이지 가로 넘침 없음. 가장 긴 E6는 각각 약 15.09px / 16.57px / 12.99px로 한 줄 전체 표시.
- 에바네시아 효과 마우스 클릭 및 Enter 열기/닫기 확인. PC 화면을 직접 열어 배치·원문·토글을 검토했다.
- FPS, GPU 합성, 실제 사용자 INP 및 200% 확대는 미측정. 툴팁 상태에 따른 상위 페이지 재렌더 비용은 남아 있으므로 전체 프레임 드랍 해결을 확정하지 않는다.
- 로컬에서는 기존 RIRA Logger 오류가 관찰됐다. 변경 코드에서 새 로그·요청은 추가하지 않았으며 이 일반 오류 메시지만으로 원인을 확정하지 않는다.

## 독립 검토

- 성능 담당 에이전트: 닫힌 8개 효과의 renderContent·DOM 생성 생략, 하위 상태 사용과 관찰자 해제 확인. 차단 사항 없음. 실제 FPS 미측정 제한 명시.
- 보안 담당 에이전트: 새 HTML 삽입·요청·권한 변경 없음, 원본 및 초기 HTML 경로 보존. 8명 원문 대조 권고를 테스트에 반영.
- 디자인 담당 에이전트: 키보드·aria-expanded·aria-controls·포커스 표시 확인. 좁은 화면 글자 크기 우려에 따라 모바일 내부 제목 여백을 조정하고 320/390/1440 실측을 추가했다. 200% 확대는 미검증.
