# 공개 블로그 콘텐츠 감사 — 2026-09-24

## 결론

기존 블로그 글 8개는 공식 자료와 대조한 출처 기록, 적용 게임 버전, 검수 이력이 없고 일부 글에는 실제 명칭과 일치하지 않거나 확인할 수 없는 고유명사·수치가 포함되어 있었다. AdSense 재검토 전 사이트 신뢰도를 우선하기 위해 8개 글 모두 공개 및 색인 대상에서 철회했다.

철회는 내용이 모두 거짓이라는 판정이 아니라, 현재 상태로는 정확성을 입증할 수 없다는 편집 판단이다. Git 이력에는 원문이 남아 있으며, 공식 출처를 확보하고 전체 내용을 다시 검수한 글만 새 글로 공개한다.

## 재공개 기준

1. 글 상단에 적용 게임 버전과 최초 작성일·최종 검수일을 표시한다.
2. 캐릭터, 장비, 스킬, 콘텐츠 명칭과 계수는 게임 내 정보 또는 공식 자료로 대조한다.
3. 외부 자료를 참고했다면 글 하단에 직접 연결되는 출처를 기록한다.
4. 공식 사실과 Rira의 해석·추천을 문장과 UI에서 구분한다.
5. `완벽`, `압도적`, `무조건`, `종결`과 같은 단정은 비교 근거가 없으면 사용하지 않는다.
6. 추천 세팅에는 추천 이유, 대체 선택지, 적용 조건과 한계를 함께 설명한다.
7. 편집 검수를 마친 글만 `BLOG_POSTS`에 추가한다.

## 후속 우선순위

검증 가능한 공식 자료가 충분한 글부터 한 편씩 새로 작성한다. 기존 글의 문장 일부만 수정해 재게시하지 않고, 실제 플레이 선택에 도움이 되는 비교·조건·근거 중심으로 다시 구성한다.
