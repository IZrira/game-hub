# 허브 홈 배치 개편 및 재사용 기준 기록

2026-10-18 KST. 기준 HEAD `50eab2a` 이후 변경 범위 검증. 전체 웹사이트 재평가가 아니다.

## 반영한 내용

- HSR·WW·NTE·Aniimo의 큰 영문 Archive 제목과 장식 통계 카드를 한국어 게임명·짧은 설명·실제 집계 `dl`로 전환했다.
- 공통 `HubIntro`로 48px 검색과 기존 경로 바로가기를 공유한다. 세 허브는 캐릭터 이름, Aniimo는 이름·번호만 검색하며 통합 장비 검색처럼 안내하지 않는다.
- HSR·WW·NTE는 최근 캐릭터를 상단으로 올리고 분석 가이드를 구분선 목록으로 표시한다. 기존 도감·티어표·파티·인벤토리 메뉴와 추천 순서는 보존했다.
- HSR·WW의 분포는 하단 native details에서 계속 확인할 수 있다. React 마운트나 JS 비용을 지연한 것은 아니다.
- Aniimo는 원본 summary의 첫 4종을 전신 `object-contain`·정사각형 영역으로 표시한다. 진화·형태 상세/가이드, 실제 서식지, 기존 비교 도감으로 연결한다. 요약 데이터에 없는 진화 관계를 연속 번호나 생성 그림으로 추정하지 않았다.
- 목업의 가상 캐릭터·풍경·날짜·커뮤니티 메뉴는 반영하지 않았다. 기존 Aniimo 공식 사이트 링크도 보존했다.

## 원본·기능 대조

- 통계는 기존 HSR_GALLERY_SUMMARY, WW/NTE galleryData, Aniimo summary·공식 habitat 배열의 값을 그대로 사용한다. Notion 동기화는 하지 않았다.
- Aniimo 표시 4종은 탄멍멍·화르랑·이글랑·헬울프이며 각 원본 URL·도감 번호·원소를 재사용한다. 브라우저에서 4개 이미지 로드와 natural size 512×840, object-fit contain을 확인했다.
- Aniimo 진화 안내는 기존 `evolution-and-forms-guide`와 상세 페이지로 연결한다. 실제 상세 계보 컴포넌트의 관계·분기·조건 데이터는 수정하지 않았다.
- 가이드 목록은 기존 공개 메타데이터·최대 3개 노출·slug·검수일을 재사용한다. 전체 가이드 본문을 허브 초기 정적 import로 넣지 않았다.

## 검증

- TypeScript: `npm run typecheck` 성공.
- Production: `npm run build` 성공. Notion 호출 없는 로컬 생성 경로를 package.json에서 확인했다.
- SEO: 사이트맵 890개 경로 감사 성공. 서식지 14개 공식 종수 검사 성공.
- 성능 예산: 진입 gzip 24,856 / 32,000 bytes, 초기 JS 139,410 / 170,000, CSS 26,847 / 34,000. 로컬 gzip 추정이며 실제 CDN 전송량·가속률이 아니다.
- 회귀 테스트: 최종 63개 파일·426개 테스트 모두 성공. 공통 소개의 제목·통계·경로·검색 인코딩과 Aniimo 검색 인계·원본 이미지·기존 기능 링크 검사를 추가했다.
- 최종 diff에서 재배치 과정의 중복 가이드 렌더링을 찾아 제거했다. 세 허브에 소개·분석 가이드가 각각 한 번만 나타나는 소스 회귀 검사를 추가했다. 첫 실행의 Windows 테스트 경로 오류도 수정한 후 타입·build·전체 테스트를 재실행하여 성공했다.
- `git diff --check`, 실제 소스·신규 파일·기존 변경 분리 검토를 수행한다. 생성기의 무관한 sitemap index 날짜만 원래 값으로 보존한다.

## 실제 화면·동작 확인

환경: Windows에서 Codex IAB, 한국어·로그아웃, `http://127.0.0.1:4174`의 production preview. 캐시 초기화·CPU/네트워크 제한 없음. 측정은 CSS px다.

- 1440×900: 네 허브 h1 시작 x=320, y=224, 높이45. 검색 입력 높이48, y=361. 본문 너비 약1080이며 브라우저 스크롤바 차이로 NTE는1082였다. 바깥 px와 사이드바 규격은 기존과 같다.
- 390×844: Aniimo h1 x16/y250, 검색 y431.5/h48. HSR·NTE h1 x16/y284, 검색 y465.5/h48. 기존 모바일 내비 구조 차이는 유지했으며 네 허브의 y값까지 동일하다고 주장하지 않는다.
- 320×844: 네 허브 검색 폼 너비280~282, 입력210~212 + 검색 버튼으로 컨테이너 내에 유지된다. Aniimo 전신 카드는 2열이고 제목·통계·바로가기는 자연스럽게 줄바꿈한다. 짧은 입력에서는 placeholder 일부가 잘릴 수 있지만 전체 접근 가능한 label을 유지한다.
- 실제 허브 검색: HSR 비소, WW 기염, NTE 감정사, Aniimo 탄멍멍이 각 캐릭터 목록의 해당 결과로 연결됨을 확인했다. Aniimo의 비교 버튼과 기존 네 가지 필터도 유지했다.
- 키보드: 입력에서 Tab으로 검색 버튼 이동 시 2px solid focus 확인. HSR·WW summary에서 Enter로 열림과 실제 분포 텍스트 확인. NTE 에스퍼 사이클 링크의 Enter 이동과 목적지 제목 확인.
- Aniimo 하단 서식지·비교·전체 메뉴를 320px에서 직접 확인했다. 신규 홈 화면의 Aniimo 콘솔 error 수집 표본은 빈 배열이었다. 모든 허브·서드파티 오류 0개로 확대하지 않는다.
- 실제 화면 증거는 사용자 로컬 시각화 폴더 `hub-layout/ww-desktop.jpg`, `aniimo-desktop.jpg`, `aniimo-mobile-320.jpg`에 보관했다. 이 절대 경로는 공개 Git에 포함하지 않는다.
