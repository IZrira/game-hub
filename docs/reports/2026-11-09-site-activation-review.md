# 사이트 활성화 검토

- 작성일: 2026-11-09
- 대상: `https://riragamehub.com/`
- 확인 범위: Search Console API(읽기 전용, 데이터 기준일 2026-11-06~07), 운영 사이트 응답, 저장소 계획 문서와 Git 기록
- 확인하지 못한 것: 실제 방문자 수와 유입 경로. Cloudflare Web Analytics 조회는 API 토큰 권한이 없어 실패했다("not authorized for that account").

## 1. 결론

기술적인 검색 문제는 대부분 고쳤다. 지금 필요한 것은 기술 수정보다 아래 세 가지다.

1. **Google 밖의 유입 경로.** 현재 확인된 유입은 Google 검색 하나뿐이고, 그 경로가 10/27부터 거의 막혀 있다. 네이버·다음·Bing 등록과 블로그·커뮤니티 연결이 없다.
2. **새 버전 콘텐츠를 빠르게 올리기.** 급락 전 클릭은 새로 나온 지역·캐릭터·장비 검색어에서 나왔다. 지금 가장 최신 캐릭터인 HSR 에이언즈★아하와 WW 쇄명에는 공략이 없다.
3. **Google 재평가를 기다리며 품질 작업 마무리.** 이미 적용한 R1~R6의 효과는 12월 초에야 보인다. 그동안 AdSense 계획의 C2·C3·C5를 끝내는 것이 검색과 재승인 모두에 도움이 된다.

## 3. 필요한 것

### P1. Google 밖의 유입 경로 만들기

**검색엔진 등록**

- 네이버 서치어드바이저: 등록 흔적이 없다(인증 파일·메타 태그 없음). 한국어 게임 검색은 네이버 비중이 커서 가장 먼저 할 일이다.
- 다음 웹마스터도구: 등록 흔적이 없다.
- Bing 웹마스터 도구: 인증 흔적이 없다. IndexNow로 URL은 보내고 있지만, 사이트맵 제출과 실적 확인은 등록해야 할 수 있다.
- 사이트 쪽 준비는 이미 되어 있다. `robots.txt`가 모든 검색 로봇을 허용하고 사이트맵 주소를 알린다. 초기 HTML에 제목·본문·내부 링크가 있다.
- 담당
  - 사용자: 각 서비스에 로그인해 사이트를 추가하고, 받은 인증 파일 이름이나 메타 태그 값을 알려 준다.
  - 에이전트: 인증 파일·메타 태그를 넣어 배포하고, 사용자가 사이트맵(`https://riragamehub.com/sitemap.xml`)을 제출할 수 있게 확인한다.

**직접 유입**

- 운영 중인 네이버 블로그(sjack03)에서 사이트로 오는 링크가 있는지 확인하지 못했다. 블로그 글마다 관련 공략·도감 페이지로 가는 링크를 넣으면 네이버 검색 유입을 사이트로 이어 줄 수 있다.
- 사이트에는 커뮤니티·SNS 링크가 없다. 새 공략을 알릴 채널(디스코드, 게임 커뮤니티 게시판 등)은 사용자가 정할 일이다. 커뮤니티 홍보는 각 게시판 규칙을 따라야 하므로 에이전트가 대신 올리지 않는다.

### P2. 새 버전 콘텐츠를 빠르게 올리기

- 공략이 없는 최신 캐릭터
  - HSR 에이언즈★아하(11/1 추가, 공략·파티 없음)
  - WW 쇄명(공략·파티 없음)
- 추천 파티가 없는 캐릭터(C5 남은 항목): HSR 길가메시·히메코•노바·미샤·링스·웰트·서벌·후크, WW 루실라·시그리카·구원·루미·유호·도기·양양·치샤. 이 중 길가메시·웰트는 급락 전 클릭이 있던 검색어다.
- 새 버전이 나오면 같은 주 안에 도감 데이터, 캐릭터 공략, 새 장비를 함께 올리는 흐름이 필요하다. 이 사이트가 클릭을 얻은 검색어는 대부분 이 시기의 것이었다.
- 담당
  - 사용자: 버전 일정, 공략 판단 메모(역할·추천 조합·운용 순서), 최종 검수
  - 에이전트: 도감 데이터 반영, 스킬·장비 문구로 사실 확인, 공략 초안과 분석 블록 작성
- 사용자 경험담이나 확인하지 않은 수치는 쓰지 않는다. 글자 수를 채우려고 얇은 페이지를 대량으로 만들지 않는다. 이번 하락이 사이트 품질 평가 때문으로 보이므로 이 원칙이 특히 중요하다.

### P3. 품질 작업 마무리(AdSense 재신청 조건)

- C2 NTE 공략: 계획 문서에는 진행 중으로 남아 있지만, NTE 캐릭터 24명 모두 공략과 분석이 있다(11/6). 남은 항목이 없으면 완료로 정리하고 재신청 조건을 다시 확인한다.
- C3 HSR·WW 세팅 공략: 대상 21편의 1차 보강은 끝났다. WW 6명의 운용 순서는 스킬 설명으로 정리한 초안이라 사용자 확인이 남아 있다. 추천 파티(HSR 4명·WW 7명)도 보류 중이다.
- C5 파티 데이터: 위 P2 목록과 같다.
- 재신청 조건 3번("2~4주 관찰 기간 동안 Soft 404 0, 색인 수 증가")은 지금 실적으로는 충족되지 않는다. 12월 초 확인 뒤 판단한다.

### P4. 측정 경로 보완

- Cloudflare Web Analytics를 볼 수 있으면 Google 밖의 유입(블로그·커뮤니티·직접 방문)을 확인할 수 있다. 사용자가 Cloudflare 대시보드에서 직접 보거나, `CLOUDFLARE_API_TOKEN`에 Account Analytics 읽기 권한을 추가하면 에이전트가 조회할 수 있다. 권한 추가는 사용자가 정한다.
- 네이버·Bing 등록 후에는 각 서비스의 실적 화면을 함께 본다.

## 4. 지금 하지 않아도 되는 것

- 추가 기술 SEO 수정: 사이트 응답, 사이트맵, canonical, 초기 HTML, 내부 링크는 정상이다. 추가 수정보다 Google 재처리를 기다리는 것이 맞다.
- 사이트맵 재제출이나 대량 색인 요청: Google이 11/8에 사이트맵을 다시 읽었다. 꼭 필요한 새 공략 몇 개만 URL 검사에서 색인 요청을 쓸 수 있다.
- 장비 noindex 기준 변경: 2026-11-09 결정대로 둔다.
