# 청석 대지·늑대이빨 능선 형태·계보 안내 보강

## 바뀐 내용

두 서식지에서 확인된 형태의 출현 정보와 진화 계보를 지역 페이지에서 바로 읽고 해당 형태 도감으로 이동할 수 있게 했다. 기존 종 수·형태 목록·필터·외곽 레이아웃과 검색 제목·canonical은 유지했다.

- 청석 대지: 풀크랩·서걱리퍼·록볼볼 기본 형태의 출현과 계보 안내.
- 늑대이빨 능선: 이글랑 기본·뇌우·천휘 형태 구분, 기본 형태 계보의 유년기·성장기·성숙기 구분.
- 같은 성숙기인 풀크랩/스탈크랩, 록볼볼/모터터, 이글랑/헬울프를 직접 이어지는 일렬 진화로 그리지 않았다. 서걱리퍼 계보의 미확인 이름은 새로 추정하지 않았다.
- 다른 지역과 웨이브 군도에는 안내를 추가하지 않았다.

## 공식 원문 대조

2026-11-16 직접 HTTP 조회한 원문을 로컬 캐시에 보존하고, 기존 공식 파서와 같은 섹션 선택자로 출현 지역·진화 단계·개체 이미지 ID를 항목별로 대조했다. 공식 페이지 이미지 ID와 프로젝트의 대응 이름을 함께 확인했다.

기존 `evolutionConditions.ts`의 레벨·시간대·날씨·재료 조건은 이번 공식 본문·상세 payload에서 확인하지 못했다. 이를 새 안내에 복제하거나 검증된 공식 정보로 표현하지 않았다. 지도·동굴 위치·좌표·획득 조건을 추정해 채우지 않았다. 기존 도감의 조건 데이터를 이번 작업에서 변경한 것은 아니다.

공개 본문에는 외부 출처·Notion 링크를 추가하지 않았고, 이 내부 검증 기록에만 공식 원문을 적었다.

## 구현

- `aniimo-hub/data/locationFieldNotes.js`: 두 지역 문구와 형태 링크의 공통 원본. 다른 지역·동일 이름의 다른 지역 ID에는 적용하지 않는다. 검색 초기 HTML 생성도 같은 데이터를 사용한다.
- `aniimo-hub/components/LocationFieldNotes.tsx`: 기존 색·글꼴·구분선으로 읽는 안내를 구성. 본문 16px, 링크 최소 높이 24px, 키보드 포커스 표시.
- `aniimo-hub/pages/LocationDetail.tsx`: 기존 요약과 개체 목록 사이에 안내를 삽입.
- `scripts/prerender-meta.js`: 검색용 초기 HTML에 동일 본문·제목·형태 링크를 같은 순서로 포함.
- `scripts/generate-sitemap.js`·`public/sitemap-aniimo.xml`: 검토한 두 지역에만 실제 검토일 2026-11-16을 변경일로 반영하고 나머지 지역 날짜는 유지.
- `tests/aniimo-location-notes.test.tsx`: 앱/초기 HTML 일치, 실제 공개 경로와 형태 키, 대상 지역 제한, 같은 성숙기 분기 보존 검증.

전체 도감 데이터나 새 이미지·라이브러리를 앱에 추가로 불러오지 않았다. 이미 사용하는 요약 목록은 그대로 둔다.

## 검증

- TypeScript 및 production build 통과. Notion 동기화 없음.
- 빌드 내 SEO 감사·성능 예산 검사 통과. 기존 공지의 짧은 설명 경고는 남아 있음.
- 전체 테스트 105파일·799개 통과.
- 빌드된 초기 HTML: 두 대상 지역에만 안내 있음. 뇌전의 숲·설산기슭 초원에는 없음.
- 로컬 브라우저: 청석 대지 1280px, 늑대이빨 능선 390px. 가로 넘침 없음, 본문 16px, 링크 높이 24px 이상, pageerror 0. 스크린샷을 직접 열어 줄바꿈·구분선·배치 확인.
- 풀크랩 기본 형태 및 이글랑 `?form=thunderstorm-form` 링크를 실제 클릭해 상세 이동 확인.
- 디자인 검사 도구의 경고는 기존 지역 헤더의 보라색 그라디언트 한 건이다. 이번 안내에서는 새 그라디언트·카드 중첩·새 팔레트를 추가하지 않았으며 기존 헤더는 범위 밖이라 유지했다.
- 성능은 빌드 예산, 보안은 내부 경로·HTML escaping과 권한 무변경, 탐색·표시는 위 브라우저 표본으로 범위를 나누어 확인했다. 별도 3인 독립 평가·전체 접근성 감사·CWV 실측은 수행하지 않았다.

Git diff·staged diff를 확인하고 이번 파일만 커밋·푸시한다. CI·운영 배포와 배포 후 실제 URL 확인 결과는 완료 응답에 별도로 보고한다. 기존 사용자 변경·생성 사본·다른 보고서는 포함하지 않는다.

## 공지에 추가할 문구 초안

- 청석 대지·늑대이빨 능선에 출현 형태와 진화 계보 안내를 추가하고, 해당 형태의 상세 도감으로 바로 이동할 수 있도록 했습니다.

공지 게시·Notion 동기화·색인 요청은 실행하지 않는다. 검색 실적 회복이나 색인 처리 시점을 보장하지 않는다.
