## 판정

**정적 콘텐츠·설계 범위 PASS. 발견한 P0/P1 없음. 실제 화면·반응형·접근성은 부모의 별도 검증이 필요하다.**

### PASS D1 — 기존 세팅과 추천 보존

`git show HEAD:hsr-hub/data/guides/어벤츄린웨이브.ts`와 현재 파일을 객체로 파싱해 analysis와 lastUpdated만 제외하고 비교했다. 나머지 객체는 동일했다. 광추·유물·장신구·목표 스탯·추천 동료·스킬 우선순위가 보존된다.

`common-hub/data/guideArticles.json`에는 diff가 없다. NTE 5개 분석은 별도 로컬 JSON에 보관되며, 기존 노션 세팅 본문이나 파티 순서를 직접 다시 쓰지 않는다. 원본 자료를 임의 수정한 콘텐츠 보강이 아니다.

### PASS D2 — HSR 조건 구분

`aventurine_waveflair.ts`의 특성·비술·환락 스킬·추가 능력 설명과 대조했다.

- 열의 10pt 도달 시 즉시 발동과 다음 아하 타임의 강화 환락 스킬을 구분했다.
- 강화 환락 스킬의 전체 열의 소모를 일반 즉시 발동으로 확장하지 않았다.
- 다른 환락 동료가 있을 때와 혼자일 때의 행적 효과를 동시에 적용하지 않도록 설명했다.
- 동료의 특정 공격으로 얻는 추가 열의의 6회 제한과 전투 스킬의 횟수 갱신을 구분했다.
- 기존 속도 180 이하 세팅을 수정하지 않으면서 필살기 속도 버프가 있는 실제 전투 수치와 나누어 설명했다.

### PASS D3 — NTE 5명 의미·수치 대조

원본은 `nte-hub/data/generated/characters.json`, `arcs.json`, `cartridges.ts` 및 기존 세팅 글이다. 현재 저장소 기준의 대조이며 최신 게임 클라이언트나 운영 Notion을 새로 검증한 것은 아니다.

- 파디아: HP 1에서 피해 분담 방향 변화, 바이레일의 HP 상한이 가장 높은 적 선택, 교대·다른 스킬 사용 시 울티메이트 추격 상태 종료, 노바 HP 상한의 한도·전투 이탈 복원과 일치한다. HP 60000을 해금 조건으로 바꾸지 않았다.
- 에드가: 바이레일은 HP가 가장 낮은 팀원, 울티메이트 영역은 현재 캐릭터를 치료한다. 시전 시간 비례 쿨타임, 진리의 열쇠 최대 3개·개당 1초, 기본 영역 10초와 일치한다. 차지의 강화 대상은 실제로 서포트 스킬로 발동한 캐릭터로 설명했다.
- 아들러: 스코치의 무작위 디버프와 동일 효과 중첩 불가, 업 최대 20·기본 중첩당 스킬 피해 2%, 각성 1의 업 즉시 획득을 기본 효과에서 제외했다. 물망산 조건은 HP가 50%보다 높을 때로 정확하다.
- 우미츠키: 카덴차 12초, 탄환 명중의 공격력 중첩 5초, 노바 종료 시 추가 피해와 일치한다. 확인되지 않은 카덴차 배율은 만들어 넣지 않았다.
- 치즈: 폰즈 10만당 최대 10중첩이므로 아크 최대 중첩의 100만 폰즈 안내가 맞다. 전투 자원인 황금 곡식과 구분했다. 곡식 비례 추가 피해의 치명타 불가, 시장 첫 정산의 치명타 보장, 길게 눌러도 정산은 한 번이라는 조건을 각각 보존했다.

### PASS D4 — 기존 디자인과 정보 구조 재사용

CSS·색상·바깥 컨테이너 규격을 변경하지 않는다. 기존 HSR과 같은 GuideAnalysis를 재사용하고, NTE 세팅/분석 버튼은 기존 GuideViewTabs를 활성화한다. navigationKey에 현재 뷰를 포함해 분석 전환 후 목차를 다시 계산하는 경로를 유지한다. 분석이 없는 글은 분석 버튼을 비활성화하는 기존 상태가 유지된다.

공개 분석은 한줄평·장점·주의점·파티 원리·운용 순서·핵심 팁으로 분리된다. 외부 출처 이름·URL, Notion 링크, 한 줄 Markdown 표를 새 본문에 추가하지 않았다.

## 미검증과 완료 조건

- 모바일 390×844와 데스크톱 1440×900 실제 화면, 운용 순서 카드의 긴 한글 줄바꿈, 이미지 표시, 가로 넘침은 이 에이전트에서 미검증이다.
- 실제 탭 전환·목차 갱신·다른 캐릭터로 이동한 뒤 상태 초기화·키보드 포커스는 부모의 브라우저/회귀 테스트 결과가 필요하다.
- 로컬 도감과 세팅의 조건 대조를 실제 게임 전투 측정이나 최신 서버 데이터 검증으로 표현하지 않는다. 전투 배율·효율 수치를 새로 계산하지 않았다.
- 타입·빌드·테스트·배포는 부모가 수행한다. 이번 검토에서 생성기, Notion 동기화, 운영 쓰기, commit/push는 실행하지 않았다.

## 교차 검토 의견

디자인 → 보안: 관리자·로그인·쿠키·권한 UI를 추가하거나 변경하지 않는다. 분석이 없는 글에 실제 검수된 분석처럼 보이는 빈 본문을 만들지 않는다. 공개 여부와 검수 날짜·작성자를 표시하는 기존 컴포넌트를 사용한다. HTML 이스케이프 및 배포 데이터 경계의 안전성 판정은 보안 역할에 맡긴다.
