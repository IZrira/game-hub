## 독립 판단

고정 URL·기기·캐시·광고·도구 버전별 독립 3회와 원자료를 보관해야 한다. 콜드·웜·SPA 이동을 구분하고 초기화가 확인되지 않은 캐시를 콜드라고 쓰지 않는다. 같은 PSI capture 결과를 다른 URL로 받은 경우 반복 횟수에 넣지 않는다.

용량 예산과 실제 전송·실행 시간은 다른 검사다. 초기 HTML·푸터 이동·이미지·폰트·공략 응답 경합·상세 전체 DB 의존을 별도로 검사한다. INP와 TBT도 분리한다.

## 현재 한계

tests/e2e는 실제 브라우저 성능 검사가 아니다. 마지막 폰트 변경 c24f68d의 실측은 미검증이다. 이전 commit의 73점·CLS 0을 최신 결과로 재사용하지 않는다.

판정: 절차 제안 완료. production 전체 성능 합격 판정은 하지 않음.

## 초안 교차 검토

광고·콘텐츠 보호와 증거 구분은 적절하다고 확인했다. 존재하지 않는 `/guides`가 정상 화면 표본에 포함된 차단점을 발견했고, 주 담당이 해당 항목을 제거했다. 문서 정확성에 대한 검토이며 실제 운영 성능 통과를 의미하지 않는다.
