## 판정 및 근거

정적 변경 범위에서 성능 차단 결함 없음. 실측 체감 개선이나 수치 개선은 확인하지 않았다.

- PASS: 세 페이지의 런타임 import·비동기 요청·데이터 조회·이미지 preload·타이머를 추가하지 않는다. 새로운 전체 DB 의존이나 전이 import는 없다.
- PASS: Home은 여백과 글자 크기 클래스만 바꾼다. 게임 선택·검색 버튼 및 기존 장식·광고를 제거하지 않는다. 검색 이벤트 처리도 그대로다.
- PASS: WW의 안내는 native details/summary로 접는다. 열고 닫기 위한 React state·이벤트 리스너·네트워크 요청을 추가하지 않는다. 안내 원문과 파티 목록·검색은 유지된다.
- PASS: Aniimo는 기존 검색/필터와 지역 탐색 섹션 순서를 교환한다. 목록 필터링·비교 선택 계산과 지역 버튼 생성 횟수는 변경하지 않는다. 4개 select·검색·지역 기능과 데이터는 유지된다.
- PASS: 신규 회귀 테스트는 런타임 진입 의존에 추가되지 않는다. 안내 원문·파티 표본·필터 개수 보존을 검사하도록 작성됐다. 이 담당은 테스트를 실행하지 않았다.
- N/A: 캐시·인증·광고 정책 변경은 없다.

## 성능 → 디자인 교차 의견

콘텐츠 삭제나 기능 제거로 수치만 개선하는 diff는 아니다. 여백·타이포·섹션 순서·선택 안내 접힘이라는 요청 범위의 변경이다. 실제 viewport별 콘텐츠 노출·접기 조작·키보드 포커스·초기 화면 전환은 디자인 담당과 주 담당의 브라우저 확인이 필요하다.
