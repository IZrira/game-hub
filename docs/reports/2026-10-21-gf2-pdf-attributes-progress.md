## 공통 보류·입력 형식

- 선호 선물: 확인된 선물 종류 3개만 입력했다. 개별 선물명은 PDF에서 아이콘만 제공하므로 임의로 이름을 붙이지 않았다. 콜펜 3/4/2, 샤크리 4/5/2, 치타 1/3/5, 나강 4/5/3, 크세니아 1/3/2.
- 결합도 보상: 기존 사용자 규칙대로 결약 보상 프로필 / 결약 보상 테두리 / 결약 보상 무기 장식 / 결약 보상 무기 스킨 네 줄이다.
- 리몰딩 코어: Lv.60 능력치와 배아~꽃 효과를 입력했다. 이미지에만 있는 재화명·성장 데이터 슬롯명은 추정하지 않았다.
- PDF에 확인되는 결합키는 전용 Notion 속성이 없어 다른 속성에 임의로 넣지 않았다. 콜펜 힐링: 공격·체력·방어 보너스 각 3%. 샤크리 아이돌의 각성: 치명타 피해·공격·체력 보너스 각 3%. 치타 천재의 행운, 나강 해트트릭, 크세니아 부자 되는 법: 공격·체력·방어 보너스 각 3%.
- 페이지 생성·이름 변경·기존 사용자 값 교정·사이트 동기화·권한 변경·이미지 변경은 하지 않았다.

## 검증과 Git

이 문서는 진행 체크포인트다. 실제 사이트 코드·데이터는 변경하지 않았다. Notion 수정은 브라우저 UI로 수행했으며, 각 속성 편집창이 닫힌 뒤 다음 필드로 이동했다. 저장 후 페이지를 새로고침하여 입력 원고와 기존 값 보존을 비교했다. Cloudflare 배포 상태는 별도 확인 전이다. AGENTS.md와 기존 다른 보고서는 이번 작업 커밋 대상이 아니다.

TypeScript 검사와 `npm run build`(SEO·성능 예산 검사 포함)는 성공했다. 원문 수치·스킬 소모·쿨타임은 추출 텍스트뿐 아니라 PDF 렌더링으로 대조했다. 빌드로 바뀐 사이트맵 날짜는 작업과 무관하여 원래 값으로 복원했다. 별도의 운영 성능·보안 감사나 웹사이트 데이터 동기화를 수행한 것은 아니다.
