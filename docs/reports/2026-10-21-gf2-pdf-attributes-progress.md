- 네메시스·캐롤릭은 이미 23개 속성이 모두 채워져 있어 기존 값을 덮어쓰지 않았다. 네메시스는 프로필·스킬·육성·스킨을 PDF와 재대조했고, 약점은 PDF 4쪽 렌더링에도 내용이 표시되지 않아 기존 경량탄/탁류 값을 유지했다. 기존 용어의 `_` 표기는 별도 정리 대상으로 남긴다. 캐롤릭은 새로고침 후 전체 기존 값 보존과 빈칸 0개를 확인했다. 중국 서버 추가 스킬 담금질 들불은 기존 패시브에 덧붙이지 않았다.
- 마지막 화면 증빙: 중간 자료 폴더의 `pdf-attributes-final-proof.png`.

실제 사이트 코드·데이터는 변경하지 않았다. Notion 수정은 브라우저 UI로 수행했으며, 각 속성 편집창이 닫힌 뒤 다음 필드로 이동했다. 저장 후 페이지를 새로고침하여 입력 원고와 기존 값 보존을 비교했다. Notion→사이트 동기화·prebuild·배포는 실행하지 않았다. AGENTS.md와 기존 다른 보고서는 이번 작업 커밋 대상이 아니다.

TypeScript 검사와 `npm run build`(SEO·성능 예산 검사 포함)는 성공했다. 원문 수치·스킬 소모·쿨타임은 추출 텍스트뿐 아니라 PDF 렌더링으로 대조했다. 빌드로 바뀐 사이트맵 날짜는 작업과 무관하여 원래 값으로 복원했다. 별도의 운영 성능·보안 감사나 웹사이트 데이터 동기화를 수행한 것은 아니다.

위 TypeScript·빌드 성공은 1차 기록 시점의 결과다. 2차 작업은 Notion 직접 입력과 이 진행 문서 갱신만 수행했으며, 사이트 코드·데이터가 바뀌지 않아 TypeScript·빌드를 재실행하지 않았다. Notion 공식 연결 도구는 현재 모델에서 사용할 수 없다는 응답이 있어 브라우저 UI로 입력·재조회했다. 2차 화면 증빙은 중간 자료 폴더의 `pdf-attributes-batch2-proof.png`다.

3차 역시 Notion 직접 입력과 이 문서만 변경하여 TypeScript·빌드는 재실행하지 않았다. 화면 증빙은 `pdf-attributes-batch3-proof.png`다. AGENTS.md 및 기존 다른 보고서는 제외하고 이 진행 문서만 Git 검증·커밋 대상으로 삼는다.

4~5차도 Notion 직접 입력과 이 기록만 변경했다. TypeScript 검사와 npm build는 재실행하지 않았으며, 위 1차 성공 결과를 현재 실행 결과로 간주하지 않는다. 현재 보고서의 `git diff --check`는 통과했다. LF→CRLF 변환 안내만 있으며 공백 오류는 없다. 마지막 재조회에서 네메시스와 캐롤릭 모두 빈 속성 0개 및 기존 값 보존을 확인했다. 웹사이트 동기화·Cloudflare 배포 확인은 수행하지 않았다.
