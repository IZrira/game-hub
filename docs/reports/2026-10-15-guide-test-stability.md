# 3인 검토 후 CI 전환 검사 보강

## 실제 실패와 범위

문서 commit 427317d의 [Quality Gate](https://github.com/IZrira/game-hub/actions/runs/38732171519/job/116412350123)는 WW jiyan 분석 전환 테스트에서 실패했다. 클릭 직후 장비 section이 제거됐다는 단정이 맞지 않았다. 로컬 변경 전 단독 실행은 19개 테스트가 통과했다. 이 증거만으로 실제 운영 탭 고장 또는 특정 타이밍 원인을 확정하지 않는다.

비동기 fetch 후 콘텐츠 마운트·effect와 즉시 DOM 단정이 겹칠 수 있는 검사 경계를 확인했다. 분석 데이터는 같은 runtime 응답에 포함되며 탭 클릭 뒤 별도 fetch를 하지 않는다.

## 조치

- tests/guide-ui-consistency.test.tsx에서 즉시·수동 해제 지연 응답을 각각 검사한다.
- 초기 마운트와 단일 클릭을 async act로 정착시키고 최종 DOM을 waitFor로 확인한다.
- 분석 버튼 활성·선택, 장비 숨김, 분석 패널 표시, 세팅 복귀·선택, 분석 제거를 모두 검증한다.
- 기존 assertion은 삭제하지 않았고 sleep·timeout 확대·실패 재시도 설정을 추가하지 않았다.
- 프로덕션 코드·데이터·디자인·광고·권한·캐시는 바꾸지 않았다.

## 3인 독립 검토

- 성능 담당: 비동기 대기·단일 클릭·기존 검사 보존 승인. 실제 CI 통과는 별도 결과로 판단.
- 보안 담당: 테스트만 변경되며 보안 경계·설정과 검증 강도 약화 없음 확인.
- 디자인 담당: 표시/숨김·양방향 복귀·선택 상태와 즉시/지연 조건 검증 승인.

## 실행 결과

- TypeScript 통과.
- 전체 36개 테스트 파일 / 298개 테스트 통과.
- 관련 파일 별도 실행 3회: 매회 20개 모두 통과. 이는 성능 실측 3회가 아니며 실패 자동 재시도도 아니다.
- npm run build, 890개 사이트맵 경로 SEO, 성능 예산 통과.
- diff --check 및 diff 검토 통과. Notion 동기화 미실행.
- 로컬 성능 크기는 진입 JS gzip 24,159, 초기 JS 138,713, CSS 26,898 bytes로 동일.
- 새 운영 전체 성능·보안·디자인 평가는 미실행. 이 조치는 CI 회귀 테스트 안정화 범위다.

남은 경고: GitHub Actions의 Node 20 기반 action 경고와 runner 이미지 변경 예고는 별개이며 이번 작업에서 설정을 임의 갱신하지 않았다. 로컬 Storage 정책 위험 후보의 운영 확인도 아직 별도 과제다.
