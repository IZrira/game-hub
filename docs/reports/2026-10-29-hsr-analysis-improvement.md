- 초기 타입 검사·빌드 PASS. 전체 회귀 테스트 71개 파일/553개 PASS.
- 메모리에서 HEAD 원본과 10개 가이드 객체를 비교해 `analysis`, `lastUpdated` 외의 데이터 동일함을 확인했다.
- 초기 빌드에서 894 sitemap URL SEO 감사와 성능 예산 PASS. 분석은 초기 HTML과 개별 해시 JSON 모두에 생성된다.
- 실제 Chromium 로컬 preview에서 미샤의 세팅/분석 탭 전환과 1440×900, 390×844 화면을 확인했다. 모바일 단계 문장은 그 결과를 보고 축약했다.
- 최종 축약 후 타입·production 빌드·894 URL SEO 감사·성능 예산 PASS. 관련 회귀 검사 5개 파일/73개 PASS. 최초 전체 회귀 검사와 최종 범위 재검사를 구분한다.
- 최종 10개 JSON과 원본 가이드 객체가 일치하며, 초기 HTML의 분석 요약·운용 순서·운용 팁도 원본과 일치했다. 분석 외 세팅 필드는 HEAD와 동일하다. 공통 반복 문구 3종은 대상 10개 분석에서 제거됐다.
- 최종 빌드 예산: entry gzip 25,305/32,000 bytes, 초기 JS gzip 139,859/170,000 bytes, 최대 chunk gzip 206,540/250,000 bytes, guide JSON 최대 32,376/40,000 bytes. 변경 10개 JSON은 5,329~15,180 bytes다. 실제 CDN 전송량·CWV 측정치는 아니다.
- 실제 로컬 브라우저에서 미샤 최종 390×844와 1440×900 분석 화면을 확인했다. 미샤 모바일 가로폭 390px에서 문서폭 390px, 블랙 스완 모바일 390px에서 문서폭 382px였고 분석 표시 및 세팅 탭 복귀가 동작했다. 화면 캡처는 로컬 시각 검증 산출물로 보관했다. 320px·200% 확대·영문/일문·게임 내 실전은 검증하지 않았다.
- 빌드의 사이트맵 인덱스 생성 과정에서 생긴 무관한 메인 사이트맵 날짜 변경은 원복했다. 이번 commit에는 실제 가이드와 생성 manifest·역할 요약·작업 보고서만 포함한다.
