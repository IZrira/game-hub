## 발견 사항

### DESIGN-001 — 검색을 닫으면 시작 위치로 포커스가 돌아오지 않음

- 판정: **FAIL / P2 / 운영에서 재현한 부분 UX 결함**.
- 영향 경로: `/`의 통합 검색. 환경은 DESIGN-E01과 같다.
- 재현: 상단 통합 검색 버튼을 열고 입력창이 포커스를 받은 상태에서 Escape로 닫는다.
- 기대: 닫힌 검색의 호출 버튼 또는 논리적인 다음 작업 위치로 포커스가 돌아온다.
- 실제: 검색은 닫혔으나 포커스가 `BODY`로 이동했다. 검색이 열린 상태의 DOM에도 dialog role이 없었다.
- 영향: 키보드·보조기술 사용자가 검색 후 탐색 맥락을 잃을 수 있다. 검색 자체가 완전히 사용 불가하다는 의미는 아니다.
- 코드 대조: `common-hub/components/SearchModal.tsx`는 입력창 `autoFocus`와 Escape 닫기를 구현하지만 호출 요소에 대한 포커스 복귀와 dialog 의미 부여는 구현하지 않는다. 이 코드 대조만으로 전체 키보드/스크린리더 적합성을 판정하지 않았다.
- 기준: 프로젝트 DESIGN.md의 키보드·의미 있는 요소·접근 가능한 상호작용 기준. [W3C APG Modal Dialog](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/)의 닫힘 후 포커스 및 dialog 패턴을 참고했다. APG 권장 패턴 위반과 WCAG 전체 부적합을 동일시하지 않는다.
- 다음 조치: 별도 수정 요청에서 열기·닫기·키보드 순회·포커스 복귀를 함께 보완하고 회귀 테스트한다. 이번 평가는 수정하지 않는다.

## 소스 검토에서 발견한 추가 위험 후보

- `FeedbackReportModal.tsx`의 제출은 API 저장 없이 타이머로 성공 UI를 표시하는 구현이다. 실제 운영 제출은 금지 범위이므로 실행하지 않았다. 따라서 운영 저장·접수는 **UNVERIFIED**이며, 성공 UI만으로 실제 제보 전달을 보장하면 안 된다.
- 같은 제보 모달의 이름·역할·입력 레이블 연결·Escape·포커스 관리도 실제 UI 재검사 대상이다. 이번 원자료에 없는 동작을 운영 재현 결함으로 바꾸지 않는다.
- 공통 Layout의 `overflow-x-hidden`은 콘텐츠 잘림을 scrollWidth 검사에서 숨길 수 있다. 스크린샷과 요소 경계 확인 없이 반응형 합격으로 판정하지 않는다.
- 기염 공략의 초기 React 준비 지연이 관찰됐다. 단일 조건 대기 timeout을 정식 성능 측정값이나 지속 장애로 단정하지 않으며, 콜드/웜·회선·third-party 조건을 고정한 성능 재측정 대상으로 남긴다.

## 범위와 미검증

총 10개 URL의 공용 관찰 자료를 받았다. 프로토콜 고정 21개 경로 중 방문한 것은 8개이고, 추가 2개는 HSR 티어표·WW 기염 공략이다. 방문은 해당 경로의 모든 상태를 검사했다는 뜻이 아니다. viewport도 실제 1272×720 하나뿐이다.

- 방문한 고정 경로: `/`, `/gallery/hsr`, `/gallery/hsr/character/feixiao/guide`, `/gallery/ww`, `/gallery/nte`, `/gallery/nte/character/감정사`, `/gallery/aniimo`, `/gallery/aniimo/character/탄멍멍`.
- 방문한 추가 경로: `/gallery/hsr/tierlist`, `/gallery/ww/character/jiyan/guide`.
- 고정 경로 미방문 13개: `/about`, `/privacy`, `/contact`, 비소 상세와 HSR 가이드 목록, `/gallery/ww/character/baizhi` 및 그 공략과 WW 가이드 목록, 감정사 공략과 에스퍼 사이클 가이드, Aniimo 목록·상성표·진화 가이드.
- 각 허브 파티 추천·다른 티어표·404·전체 메뉴 링크·검색 결과 선택 이동도 미검증이다.

따라서 21개 고정 경로 및 추가 티어표/파티/상태 전체 matrix 합격이 아니다. 기염은 WW의 추가 표본이며 고정 `/gallery/ww/character/baizhi`와 그 공략 검사 완료로 대체하지 않는다.

- 390×844·1440×900·320×844·768×1024: **UNVERIFIED**, 도구 설정이 실제 viewport에 반영되지 않음.
- 200% 확대·다국어·긴 이름·실제 모바일 터치·reduced-motion: **UNVERIFIED**.
- WCAG 2.2 대비 수치·대상 크기·전체 키보드 여정·스크린리더·자동 접근성 검사: **UNVERIFIED**. 색상 클래스나 Lighthouse 점수로 대체하지 않음.
- 로딩 실패·이미지 강제 실패·재시도·저장/제보 성공: **UNVERIFIED**. 운영 장애 주입·쓰기는 실행하지 않음.
- 실제 콘솔·네트워크 오류 전체 수집: **UNVERIFIED**. DESIGN-E04의 현재 탭·제한된 error 로그 조회만 확인했으며 소스 검사나 빈 조회 결과로 전체 오류 0개를 주장하지 않음.
