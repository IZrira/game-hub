# NTE 전용 세팅 공략의 글 단위 로딩

기준 커밋 e8b3f26. NTE CharacterGuideDetail의 전체 guideArticles 정적 의존을 제거하고 공통 useGuideArticle 로더를 사용한다. 원본 데이터와 기존 파서·디자인·아크·콘솔·옵션·목표·육성·시너지 표시를 유지했다.

## 변경과 검증

- 가이드 식별은 요약 메타데이터로 수행한다. 기존 slug, characterId, 제목 기반 연결 조건을 그대로 유지한다. 등록되지 않은 공략은 본문을 요청하지 않는다.
- 실제 본문은 해당 글의 기존 해시 JSON만 요청한다. 감정사 본문 JSON은 2,456 bytes다. 전체 원문 파일 94,405 bytes와 달리 다른 글 본문을 함께 받지 않는다. 이 비교는 비압축 원본/JSON 기준으로 실제 페이지 전송량·압축 번들·로딩 시간 감소율이 아니다.
- 공통 로더의 요청 취소·늦은 응답 무시·응답 ID 검증·재시도·장기 캐시를 재사용한다. 로딩 중에는 요약 SEO를 유지하고 일시적 로딩을 noindex/없는 공략으로 표시하지 않는다.
- 로드된 캐릭터별 콘텐츠를 key로 분리해 이동 시 콘솔 선택을 초기화한다. 같은 캐릭터 내 콘솔 전환은 기존 UI로 유지한다.
- 기존 세팅 테스트를 비동기 로딩 완료 후 검증하도록 바꿨다. 전체 본문 재번들 방지, 없는 경로 무요청, 503 후 재시도, 다른 캐릭터 이동·콘솔 초기화·해당 글만 요청하는 검사도 추가했다.
- 타입 검사, 전체 테스트 33개 파일·280개 테스트, 빌드·890개 경로 SEO·성능 예산 검사 성공.
- 브라우저에서 감정사 추천 장비·세트·옵션·육성·시너지 섹션과 기본 요약을 확인했다. '잃어버린 빛'으로 전환 시 요약과 2/4세트 효과가 함께 바뀌고 기본 목표가 유지되는 것을 확인했다.
- 현재 빌드 초기 JS gzip 합계 138,602 bytes로 예산 170,000 이하이며 이전 138,584 bytes와 거의 같다. 이번 작업은 NTE 상세의 불필요한 전체 본문 다운로드·파싱 제거가 목적이다.
- 성능 유지 MD에 NTE 적용과 전체 원본 런타임 정적 참조 금지를 기록했다. Notion 동기화와 공략 데이터 수정은 하지 않았다. 사이트맵은 빌드에서 재생성·감사하며 추적 내용 변경은 없었다.
