기준: 기존 원본·이미지·공개 URL 보존, 공식 신규 데이터만 별도 추가. Notion 동기화는 실행하지 않았다. AGENTS.md와 기존 미커밋 보고서는 이번 commit에서 제외한다.

- 신규 29종·42형태를 별도 원본 파일에 수집했다. 기존 86종과 합계 115종이다.
- 기존 원본 SHA-256: `a0d257b7dc68db76fa3a532668be565288ef576f5e767ba72e9d96effab0cb93`. 수집 전후 및 회귀 테스트에서 동일했다.
- 서로 다른 공식 일러스트 주소 40개는 모두 이미지 HEAD 응답이 정상이었다. 아쿠루·아쿠링의 일부 형태는 공식에서 그림을 공유한다.

## 연결과 보존

신규 내부 ID·상세 JSON 파일명을 `wave-archipelago-NNN`으로 분리했다. 기존 No.001 탄멍멍과 신규 No.001 쉘코랄은 독립적으로 검색·비교·이동된다. 기존 영문명과 진화 조건의 번호 매핑을 신규 도감에 적용하지 않는다.

검색 통계·도감 요약·상세 JSON·허브·사이트맵·검색용 초기 HTML에 결합 데이터를 연결했다. 새 출현 지역 4곳은 기존 14개 서식지와 경로를 분리했다. 공식 표기의 `미확인 구역`은 원문 텍스트로 보존하며 독립 페이지를 생성하지 않는다. 신규 장소가 한 곳만 표기된 사실로 독점 출현을 단정하지 않는다.

## 검증

- TypeScript 재검사 통과. 첫 검사에서 신규 테스트 JSON의 추론 타입 오류를 발견해 명시적 AniimoEntry 타입으로 수정했다.
- 전체 테스트 76파일·591개 통과. 이후 미확인 장소·표시 정책 변경 관련 4파일·18개 테스트를 재검사해 통과했다.
- 최종 코드 전체 재검사: 2026-10-31 16:24 KST, 76파일·592개 테스트 통과.
- 기존 14개 서식지 종 수 대조 통과.
- 최종 전체 빌드 통과. SEO 947개 사이트맵 경로 검사와 고정 성능 예산을 통과했다. 로컬 gzip 추정: 진입 JS 25,287 bytes, 초기 JS 139,841 bytes, 최대 chunk 206,540 bytes. 실사용 속도 수치로 환산하지 않았다.
- 최초 빌드에서 `미확인 구역`의 얇은 독립 페이지가 SEO 검사를 실패했다. 원문은 보존하고 독립 위치 페이지 생성을 제외한 뒤 SEO 검사를 통과했다. 검사 임계값을 낮추지 않았다.
- 실제 PC 1440×900과 모바일 390×844에서 신규 도감 29개 카드, 쉘코랄 기본/우천 이미지 전환, 동일 번호 동시 비교, 웨이비핀 폭풍 형태의 미확인 성장기 노드, 새 초승달 만 경로를 확인했다. 확인한 화면에 가로 넘침이 없었다.
- 로컬 빌드가 진행 중인 이전 페이지에서 삭제된 이전 chunk 요청이 실패한 사례는 새 빌드 완료 후 reload해 해소했다. 최종 화면의 콘솔 검증과 구분한다.
- 최종 빌드 reload 후 도감 29개 카드·확인일 2026-10-31·초승달 만 지역·독점 출현 문구 제거를 다시 확인했다. 최종 여정 이후 새 console error는 없었고 로그에는 앞서 발생한 07:19:41 UTC의 이전 chunk 오류만 남아 있었다.
- 성능·보안·디자인 별도 담당의 보고서를 함께 보관한다. 디자인 최종 시각 증거는 주 담당의 브라우저 확인을 포함하며 독립성 한계를 구분한다. 전체 사이트 CWV·침투 테스트·부하 테스트로 확대하지 않는다.

## 공식 정보의 한계

부엉파·홀부엉 계보의 별도 아이콘 대상 이름, 웨이비핀·서지윙 폭풍 형태 성장기 이미지와 대상은 공식 도감에서 확정하지 못했다. 미확인 비링크 상태로 보존했다. 공식 진화 조건이 없는 부분은 기존 번호의 조건으로 채우지 않았다. 신규 `땅` 원소의 기존 상성 계산 연결은 공식 관계 검증 전까지 확장하지 않았다.

재수집·검증 방법은 `docs/guides/ANIIMO_DATA.md`를 따른다.
