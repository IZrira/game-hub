# NTE 캐릭터·아크·아이템 DB 동기화

작성일: 2026-10-22. 사용자 요청으로 공식 스크립트 `node --use-system-ca scripts/fetch-notion-data.js --nte-only`를 실행했다. Notion 원본에 쓰지 않고 사이트 원본 프로젝트에 반영했다.

## 반영 결과

- 캐릭터 23 → 24명. 신규 아카네 린.
- 아크 50 → 51개. 신규 달의 대척점.
- 아이템 1,023 → 1,230개. 앞선 작업으로 추가한 207개가 전부 포함됐다.
- 생성된 인벤토리 표시 통계는 기존 로컬 보완 항목까지 포함해 1,231개다. Notion 원본 수 1,230개와 구분한다.
- 캐릭터·아크 상세 런타임, 목록 요약, 공통 아이템 런타임, 검색 색인·홈 통계, 사이트맵·초기 HTML·Cloudflare 라우트 목록을 재생성했다.
- 기존 다른 게임 403개 원본 레코드가 내용과 순서까지 동일하게 유지됐음을 Git 원본 바이트와 비교했다. PowerShell 파이프의 잘못된 UTF-8 변환을 배제하여 재확인했다.
- 전체 원본 데이터의 중복 ID 16개는 이전부터 존재하며 이번에 늘지 않았다. 이 작업에서 무관한 기존 ID를 변경하지 않았다.

## 검증

- `npm run typecheck` 통과.
- `npm run build` 통과. 자동 Notion 재동기화 없이 실행했다.
- 빌드 내 SEO 초기 HTML 검사: 사이트맵 892개 경로 통과.
- 성능 예산 검사 통과. 초기 JS gzip 추정 139,478 / 170,000바이트, 최대 청크 206,386 / 250,000바이트.
- NTE 관련 테스트 5개 파일, 51개 테스트 통과. 최초 제한 샌드박스에서는 두 테스트 파일이 임시 파일 ENOENT로 실행되지 않았으나 추가 권한 환경에서 동일 테스트를 재실행해 전부 통과했다.
- `npm run validate:data` 통과. 이 검사의 로컬 아크 9개 수치는 Notion 51개와 별도 원본임을 구분한다.
- 신규 캐릭터·아크의 생성 HTML에서 title·H1·canonical과 Notion 링크 비노출을 확인했다.
- 신규 캐릭터와 아크의 GitHub 원본 WebP 이미지 URL이 모두 HTTP 200 및 WEBP 형식임을 확인했다.
- 로컬 미리보기 서버는 실행됐지만 브라우저 연결은 timeout으로 열리지 않았다. 빌드 성공을 브라우저 화면 확인으로 대체하지 않는다. 운영 확인은 push·자동 배포 후 별도로 확인한다.

## 범위와 주의 사항

- 이전 승인대로 미번역 보류 22개·이미지 조건 불충족 6개는 Notion에 추가하지 않았으므로 이번 새 아이템 207개에 포함되지 않는다.
- 신규 아이템의 원본에 없는 분류·설명·성급 등은 앞선 누락 보고서대로 빈 값이다. 동기화가 누락 정보를 만들어 주지는 않는다.
- 아이템 이미지 207개는 이미지 저장소 커밋 `e90106e`로 이미 업로드됐다. 이번에는 이미지를 다시 업로드하지 않았다.
- 기존 디자인·기능은 수정하지 않았다. AGENTS.md와 기존 다른 미커밋 보고서는 커밋 대상에서 제외한다.
- GitHub push 후 자동 배포 구조이므로 별도 중복 배포 명령은 실행하지 않는다. 해당 커밋의 CI·Cloudflare·운영 접근 상태는 최종 응답에서 구분해 보고한다.
