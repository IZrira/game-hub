# 홈 초기 전환 안정화

## 변경

홈의 lazy chunk와 번역을 병렬로 준비하고, 완료 전에는 기존 초기 HTML을 유지한다. 준비된 Home은 동기 렌더링해 중간 Suspense 화면과 푸터의 일시적인 상승을 방지한다. 다른 페이지로 직접 진입할 때는 Home chunk를 요청하지 않는다. 디자인·데이터·광고 정책은 변경하지 않았다.

## 검증

- TypeScript 통과, 테스트 35개 파일 / 296개 통과.
- build, 890개 사이트맵 경로 SEO 감사 및 성능 예산 통과.
- 초기 HTML 유지, 직접 상세 진입 시 홈 미요청, 홈 chunk 실패 시 재시도 테스트 추가.
- 로컬 미리보기에서 데스크톱 및 390px 모바일 홈 렌더링 확인.
- Notion 동기화 미실행. 사이트맵은 기존 빌드 생성기로 검증했으며 URL 변경은 없다.

## 크기와 한계

로컬 gzip 추정: 진입 JS 24,048 → 24,159 bytes, HTML modulepreload 포함 초기 JS 138,602 → 138,713 bytes. 증가분 각각 111 bytes. CSS 26,898 bytes, 최대 chunk 206,387 bytes로 예산 내다.

이번 변경은 중간 로딩 레이아웃을 제거한 것이며 초기 HTML과 실제 홈의 구조 차이 및 폰트 교체까지 없앤 것은 아니다. 배포 후 독립 PageSpeed 실측 전에는 CLS 감소량이나 속도 개선율을 확정하지 않는다. TBT를 INP로 간주하지 않는다.
