# UI점검

호출: `UI점검` 또는 `$rira-ui-check`. RIRA 프로젝트 원본은 `D:\rira game hub\game-hub`이며 다른 경로에서는 Git remote가 `IZrira/game-hub`인지 확인한다.

AGENTS.md와 DESIGN.md, git status를 확인한다. 대상 허브·URL·섹션과 사용자가 지정한 기준 화면을 고정한다. 수정 요청이 없으면 읽기 전용 비교만 한다.

1. 관련 컴포넌트를 docs/design-system/components.md와 실제 Props에서 찾는다. 외부 추천보다 기존 디자인·컴포넌트·사용자 의도를 우선하고 같은 역할의 컴포넌트를 복제하지 않는다.
2. 동일 viewport·언어·데이터 상태에서 기준 화면과 비교한다. 바깥 컨테이너·여백과 내부 카드·초상화·글꼴 크기를 분리해 측정한다. 같은 부분은 유지하고 필요한 차이만 수정한다.
3. 제공되는 브라우저 도구로 실제 렌더링을 확인한다. 데스크톱·모바일의 줄바꿈·잘림·카드 수·이미지 비율과 키보드 포커스를 확인한다. 지원되지 않는 viewport나 권한 상태는 미검증이라고 밝힌다. overflow 숨김으로 잘림을 가리지 않는다.
4. docs/design-system/ux-principles.md에서 해당 상태만 확인한다. loading·empty·error를 정상 데이터 화면으로 오해하지 않고, 대체 캐릭터 펼침·탭·링크 등 영향받는 상호작용을 검사한다. 운영 저장·댓글·관리자 동작은 읽기 점검에 포함하지 않는다.
5. 수정 요청이 있으면 공통 규격을 재사용해 최소 변경한다. 실제 콘텐츠·아이콘·추천 순서·기존 바깥 여백을 보존하고 회귀 테스트와 AGENTS.md의 타입·build·diff·Git/배포 검증을 수행한다. 시각 변경 후 화면을 직접 보고 자동 테스트만으로 디자인 완료를 선언하지 않는다.

새 색상·서체·테마·디자인 시스템 제안은 사용자가 요청할 때만 한다. 접근성 도구의 점수를 전체 적합성으로 표현하지 않는다.

결과는 기준·실제 크기/차이·유지한 부분·수정 파일·화면/상호작용 검증·미검증 항목을 짧게 보고한다. 전체 3인 독립 평가를 실행하지 않았다면 수행했다고 표현하지 않는다.

참고가 필요할 때만 [UI UX Pro Max 원본](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill)을 확인한다. 외부 스타일이나 CLI 설치를 자동 적용하지 않는다.
